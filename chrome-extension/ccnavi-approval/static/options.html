リポジトリ

    直近の日数と指定のブランチは、承認待ちを見つけるのに使うだけです。判定には統合先・親のブランチ・先行の閉包だけを入れます（ADR-0093 の D2）。

    PAT

      承認・取り下げ・レビュー済みを親のブランチへ書きます（段階 4）。レビュー済みは MR のスレッドとレビューを読みます（Pull requests: Read-only で足ります）。GitHub の fine-grained token でリポジトリを限り、Contents: Read and write・Metadata: Read-only・Pull requests: Read-only を選びます。期限は 90 日を選びます。エージェント用のトークンとは別にします。PAT はこのブラウザのプロファイルに平文で置かれます（ADR-0093 の 5.5）。期限はホストの応答から読みます。読めないときは上の欄の日付を使い、切れる 7 日前からボードとアイコンで知らせます。
