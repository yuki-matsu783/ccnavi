# 差分は分岐元から見る

- ブランチの変更は `diff <統合先>...HEAD`（3 点）で見る。分岐元から HEAD までの差になり、そのブランチが入れた変更だけが出る
- `diff <統合先>`（2 点）は、統合先が分岐後に進んだ分も「ブランチで消えたもの」として出る。ブランチが追加していないファイルの大量の削除が見えたら、2 点の差を疑う
- 統合先が進んでいるかは `log HEAD..<統合先>` で確かめる。進んでいたら、レビューを頼むときも 3 点で見るよう差分の取り方を添える
- レビューを別のエージェントに頼むときは、差分の取り方（3 点か 2 点か）を依頼文に書く。書かないと、相手が 2 点で見て、存在しない削除を指摘することがある
