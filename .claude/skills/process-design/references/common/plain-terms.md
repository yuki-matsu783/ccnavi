# 説明と提案で内部の呼び名を使わない

- issue のタイトルや作業中の呼び名（比喩・略語）を、提案・設計書・ユーザへの説明にそのまま使わない。書いた人と issue を読んだ人にしか通じないため
- 何が起きている状態かを言葉で書く。例: 「孤児のワークツリー」という呼び名は、「元のプロジェクトが無いワークツリー」と書く
- 短い呼び名を使い続けたいときは、初出で定義を添える。用語集に入れるかは別に判断する
