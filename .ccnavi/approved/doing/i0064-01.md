# 置き場を既定に固定する方針を ADR-0084 に書く

親 i0064 のフェーズ 1（design）。実装には入らない。

## 書くもの

`docs/adr/0084-places-are-fixed-to-defaults.md`

| 節 | 中身 |
|---|---|
| 背景 | 置き場を動かす env が 6 つあり、変えている配布先が見当たらないこと。読む側ごとの分岐と食い違い（絶対パス、拡張が `CCNAVI_TICKETS_PROPOSAL` を読まない、sh の綴りの正規化） |
| 決定 | 置き場は既定だけ。要望が出たらそのとき口を足す。消す 6 つ、空文字の「止める」口も消すこと、残った値は無視して止めないこと、上書き設定ファイルの同じキーも読まないこと |
| 線の引き方 | 残す `CCNAVI_BIN_PATH`（既定を持たない設計・守る対象の鍵）、`CCNAVI_WORKSPACE`（見つけられないときの逃げ道）、診断のフラグ（次のチケット）。何が「置き場を動かす口」で何がそうでないか |
| 導入済みの環境 | 導入スクリプトが `env` から 6 つを外し、既定と違う値を名指しすること |
| ぶつかり | `projects/` が追跡されているときの条件・知らせる 3 か所・文面・warn にとどめる理由。既存の「無視されていない」を出さない理由。他の置き場を扱わない理由 |
| 得るもの / 失うもの / 代案 | 親の提案から写し、ADR として読める形に整える |

既存の ADR は書き換えず、該当箇所に「ADR-0084 で置き場の env を消した」旨の参照を 1 行ずつ足す。

| ADR | 足す場所 |
|---|---|
| 0052 | プロジェクトの層の置き場の表（`<CCNAVI_PROJECTS>/<名前>/<CCNAVI_PROJECT_HOME>/…`） |
| 0067 | 「数えない」を `CCNAVI_PROJECTS=""` で言う形を選んだ箇所 |
| 0077 | `CCNAVI_PROJECTS` を変えた配布先に触れている箇所 |

## 得るもの

- 実装の前に、消すものと残すものの線が 1 か所に書かれる。以後の子はこれを参照すればよい
- 「要望が出たら足す」を方針として残すので、次に口を足したくなったときの判断の根拠になる

## 失うもの

- 親の提案と ADR に同じ中身が 2 度書かれる。親の提案は承認で動いたあと読まれなくなるので、
  正本は ADR にする
- 過去の ADR に参照を足すので、読む人は 2 本を行き来する

## やらない場合

実装とテストの子が、線の引き方を親の提案から読むことになる。提案は閉じたあと
`done/` に埋もれるので、後から「なぜ env が無いのか」を辿れない。
