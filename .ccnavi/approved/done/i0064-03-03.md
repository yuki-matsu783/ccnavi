## 代案

1. **07 を活かし、0093 の代わりに 0098 をコードにも書く。** コメントから ADR へ番号で辿れる。代わりに、A の PR の番号が
   変われば、コード・テストと保護済みの sh（人が写す）をもう一度直す。0092・0093 と 2 度続けて起きたことがまた起きうる
2. **番号の代わりに ADR のファイル名（`places-are-fixed-to-defaults`）を書く。** 番号が動いても辿れる。
   代わりに、ファイル名は番号付きで置くので、名前の後ろ半分だけを書く形がこのリポジトリに無く、決まりを 1 つ足すことになる
3. **`test_adr_numbers.py` を main と同じ文字でこの子でも直す。** 06 までの間も題の検査が通る。
   代わりに、同じ直しを main と i0064 の 2 か所で書く（利用者の決定で採らない）
