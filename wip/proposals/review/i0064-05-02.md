### 0098 の冒頭

今の注記「この ADR は番号を先に押さえるために置いた。実装はチケット i0064 で入る。それまでは main の実装は環境変数で置き場を動かせるままである」は、
親を統合すると事実と合わなくなる。この注記を、次の中身の追記に差し替える。

- 実装はチケット i0064 で入った。チケットの本文（`.ccnavi/approved/` の下）では、番号を main で押さえる前の仮の番号 ADR-0084・ADR-0092・ADR-0093 でこの決定を指している。それらは main では別の決定の番号

- 「関連」に無いもの: ADR-0017・ADR-0075（実行後チェックが記録と控えの置き場を env の名前で除く）、ADR-0089・ADR-0092（記録の置き場）、ADR-0093（12 の「置き場の綴りが絶対パスのワークスペースは C1 と Chrome の対象外」は起きなくなった）

### ADR-0089 の冒頭（分岐 2）

「決定の表の『動かした置き場（`CCNAVI_LOG` / `CCNAVI_STATE`）にも当てる』は、ADR-0098 で env を廃止したので、診断のフラグ `--log` / `--state` で動かした置き場を指す。当てる範囲は変わらない。
採らなかった案の『`CCNAVI_LOG` の意味（1 本のファイル）』も、固定の `logs/decisions.jsonl` 1 本と読む」。

### ADR-0092 の冒頭（分岐 5）

main の ADR-0092 は、決定の表で「環境変数 `CCNAVI_LOG` … の名前は変えない」、失ったものに「残したいならユーザが名前を変えるか、`CCNAVI_LOG` で古い名前を指す」と書いている。

導入スクリプトは、以前書いた `CCNAVI_LOG=logs/log.jsonl` を既定と違う値として名指しして外す」。
