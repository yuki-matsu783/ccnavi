管理画面の「あやしい挙動」を、決まりに合わせて直しました

ccnavi の VS Code 拡張には、ルール・フェーズ・リスク・テンプレートを直す「管理画面」があります。前の作業（#740）で直しきれず、「決まりを確かめてから」と残した項目（#743）を、決まりと照らして直しました。

何が変わったか（画面ごと）

画面前後
ルール・リスク・フェーズ保存すると警告（warn）があっても、件数しか見えなかった警告の本文が画面の上の帯に出る。次の編集か更新で消える
ルール「期待と食い違う」行の「ヒットしたルール」が、組み込みの保護が理由だと空だった「（ルールファイル外の根拠）」と出る
ルール絞り込みで 0 件でも何も出なかった「絞り込みに一致するルールがありません」と出る
3 画面絞り込み中に「↑」「↓」を押すと、隠れた行をまたいで動いた絞り込み中は並べ替えボタンが押せない
3 画面全角の英字（「ＡＢ」）で絞り込めなかった半角と同じように一致する
テンプレート編集中に、外から別のテンプレートに切り替えると古い編集欄が残った編集中は切り替えず、「保存か破棄してから」と知らせる
テンプレート子のフロー編集の案内に、無い機能（グループ化・コピー）が載っていた無い機能の案内を外した
テンプレート名前に con や a. が付けられた（Windows ではファイルにできない）新しく作る名前と下書きの名前では断る
テンプレート狭い画面で、計画の表の操作ボタンが横にスクロールしないと見えなかった操作の列を右端に固定した
フェーズ「none（既定）」と出ていたが、本当の既定は mr だった「既定」の文字を消した
フェーズ区切りの注意が無く、全角の「、」で打つと 1 つの値になった入力欄に「区切りは半角 ,」と書いた

あえて直さなかったこと

  • 同じ id を重複させて保存すると古い行も開く件：重複 id は警告で直す状態で、仕様どおり
  • 全角の「、」を区切りとして受け取ること：決まりでは半角 , のみ
  • 狭い画面で計画の表を縦に積み替えること：作り込みが大きく、操作列の固定で足りる

決まりの文書も直した

決まりが書かれていなかった挙動は、先に要件書へ 1 文足してから直しました（ルール・フェーズ・リスク・テンプレートの 4 本）。

確かめてほしいこと（実機）

  • 保存後に警告の帯が出て、次の編集で消えるか
  • テンプレートを編集中に、外から別のテンプレートを開こうとして、通知が出て切り替わらないか
  • 狭い幅で計画の編集欄を開いて、操作の列が右に固定されて見えるか

自動テストは変えた範囲で通っています（TypeScript 309 件、Python 26 件）。上の 3 点だけは、テストでは確かめられていません。
