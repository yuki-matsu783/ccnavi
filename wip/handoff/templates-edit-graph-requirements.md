# テンプレートの編集欄の図の操作（3〜5）の要件の案

合意したら、`extensions/vscode/ccnavi-board/docs/requirements/templates.md`の「編集」の節（と、5は図の部品を共有する`workflow.md`）に書き写す。
ここに書かないこと（保存の条件・作業中の錠・図の中身を実行ファイルの答えのまま描くこと）は、今の要件のまま変えない。

## 3. ステップの操作を図にまとめる

今は、線は図、種類とレビューは表、子のフローは別の節で直す。同じステップを3か所で番号で突き合わせることになる。

| 部分 | 約束 |
|---|---|
| 選ぶ | 図のステップを押すと、そのステップを選ぶ。表の行の番号を押しても同じステップを選ぶ。選んだステップは図の点と表の行の両方で目立たせる。図の空いた所を押すと選ぶのをやめる。選んだステップは番号ではなくステップそのものに付く（番号が振り直っても同じステップを選んだまま） |
| 詳細の欄 | 図の右に、計画編集タブと同じ詳細の欄を出す（畳める。畳んだかは計画編集タブと同じく画面が覚える）。選んだステップの番号・タイトル・先行と後続・すぐ始まるか・終端に届かないかを、実行ファイルの答えのまま読むだけで出す |
| 詳細の欄で直す | 種類とレビューの指定を、表と同じ選択肢で直せる。「削除」も置く（表の削除と同じ決まり。全体計画の最後の1ステップは消せず、子のフローがあれば消えることを先に言う） |
| 子のフロー | 全体計画のステップを選んだとき、詳細の欄に「子のフローを足す」か「子のフローへ移る」を出す。移ると、子のフローの節のそのステップの図を開いて、画面をそこまで送る |
| 子のフローの見出し | 子のフローの節の各行の見出しを「番号 型」から「1:設計 のフロー」の形にする（一覧の図と同じ。タイトルは実行ファイルの答えのまま） |
| 表 | 今の表は残す（並べ替えは表でだけ行う。図の上の位置と番号は別のものなので、図には並べ替えを置かない） |

## 4. 図からステップを足す

今は末尾に足すだけで、先行は前の末尾のステップに決まる。並行するステップを作るには「足す → 線を消す → 線を引く」の3手が要る。

| 操作 | 約束 |
|---|---|
| この後に挟む | 選んだステップの直後に、新しいステップを1つ挟む。新しいステップは選んだステップを先行にし、選んだステップを先行にしていたステップは、代わりに新しいステップを先行にする（直列の途中に入る） |
| これと並べて足す | 選んだステップと同じ先行を持つ新しいステップを足す。選んだステップを先行にしていたステップは、新しいステップも先行にする（並行に走って、同じ所で合流する）。選んだステップが最後のステップのときは合流先が無いので、新しいステップは終端に届かないステップになる（そう出すのは実行ファイルの答え） |
| 型 | 足すステップの型は、詳細の欄の「足すステップの種類」で選ぶ（末尾に足すときと同じ選択肢） |
| 番号 | 足したあとは、今と同じく先行が自分より小さい添字になるように画面が番号を振り直す |
| 置き場所 | 新しいステップは、組んだ図の場所に置き、ほかの点と重なるなら空くまで下へずらす（ほかの点は動かさない） |
| 選ぶ | 足したステップを選んだ状態にする（続けて種類を直したり、さらに足したりできる） |
| 末尾に足す | 表の下の「ステップを足す」は今のまま残す |

## 5. 引けない線の理由を出す

今は引けない線を放しても何も起きず、なぜ引けないのか分からない。テンプレートの編集欄と計画編集タブの両方の図（同じ部品）に入れる。承認のオーバーレイの図は読むだけなので変わらない。

| 場面 | 約束 |
|---|---|
| 引いている最中 | 線を引けるステップと引けないステップを、見た目で分ける（引けない点は薄くする）。色だけに頼らず、点の上に載せたときの説明でも言う |
| 放したとき | 引けない所で放したら、図の下に理由を一言出す。次に図を触るか、少し経つと消える |
| 理由の文 | 自分へ:「自分自身へは線を引けません」。startとend:「開始と終了への線は図が自動で引きます」。循環:「この線を引くと順序が輪になります（Nの先行をたどるとMに戻ります）」。子が承認された番号（計画編集タブだけ）:「子が承認された番号です。入る線は変えられません」。すでにある線:「この線はもうあります」 |
| 判定 | どの線を引けるかは今と同じ（画面が引いている最中に断る条件のまま）。新しい条件は足さない。順序の正否は今と同じく実行ファイルの答え |

## 要件の表に足す行（案）

| ID | 区分 | 要件 |
|---|---|---|
| REQ-VSC-41 | 事象 | テンプレートの編集欄で計画の図のステップか表の行を選んだとき、拡張は図の右の詳細の欄に、そのステップの実行ファイルの答えを読むだけで出し、種類・レビューの指定・削除・子のフローを足すか移る操作を出すこと。選んだステップは番号が振り直っても同じステップに付いたままにすること |
| REQ-VSC-42 | 事象 | テンプレートの編集欄でステップを選んで「この後に挟む」「これと並べて足す」を押したとき、拡張は新しいステップを足し、先行を、挟むなら選んだステップと後続の間に、並べるなら選んだステップと同じ先行と同じ後続に付けること。足したあとは番号を振り直し、ほかの点を動かさず、足したステップを選ぶこと |
| REQ-VSC-43 | 事象 | 計画の図（テンプレートの編集欄と計画編集タブ）で線を引いている間、拡張は引けないステップを見た目と説明で分け、引けない所で放したら理由を図の下に出すこと。どの線を引けるかの条件は変えないこと |

## 決めてほしいこと

- 3の並べ替えを表だけに残す（図には置かない）でよいか
- 4の「これと並べて足す」で、後続も新しいステップを待つ（合流させる）でよいか。待たせない（枝分かれのまま終端へ）ほうがよければそちらにする
- 5を計画編集タブにも入れてよいか（同じ部品なので、入れないほうが手間がかかる）
