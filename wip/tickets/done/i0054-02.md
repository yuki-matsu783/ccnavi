## 前提の訂正（i0054-01 で分かったこと）

`--rules` / `--phases` / `--risk` は **CLI フラグとしても存在し、env とは別の経路**
（`cli.py:205,232,233` と `OVERRIDES`）。`tests/config` の全テストがこのフラグで自分の
一時ディレクトリを指すので、**フラグは消さない**。消すのは env の 1 本だけ。

親チケットの「共通層を既定の外へ置く手段が無くなる」は言い過ぎで、正しくは
「env 経由の手段が無くなる。hook の command に `--rules <パス>` を足す道は残る」。
