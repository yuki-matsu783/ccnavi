## 書くテスト

### 渡す回の刻み（`tests/config/`）

| 何を言うテストか |
|---|
| `every: 5` のルールは 5 回目に当たったときだけ文を渡す。1〜4 回目は渡さない |
| `additionalContext` は 10 回目にも渡す（倍数ごと） |
| **`additionalContextOnce` は 5 回目だけ。10 回目には渡さない** |
| `every` が無いルールはいままでどおり毎回渡し、`Once` は 1 回目に渡る |
| `every: 1` と書いたルールが、`every` を書かないルールと同じ結果になる |
| `additionalContextOnce` だけを持つ `every: 5` のルールは、5 回目に 1 度だけ渡す |
| `additionalContextFile` は `additionalContext` に、`additionalContextOnceFile` は `Once` に従う |

### 控え（`tests/config/`）

| 何を言うテストか |
|---|
| 控えがセッションと `agent_id` で分かれる。サブエージェントは自分の数えを持つ |
| 古い形（配列）の控えを読んでも落ちない |
| `--state ""` のときは毎回渡す（`ctxfile.py:108` の既存の決まりに合わせる） |
| `every` も `Once` も持たないルールでは、控えに数えを書かない |

### `--lint`（`tests/core/`）

| 何を言うテストか |
|---|
| `every: 0` と `every: -1` と `every: "x"` を error にする |
| `every: 1` には何も言わない |
| 文を 1 つも持たない `every` を warning にする |
| `additionalContextOnce` だけを持つ `every` は warning にしない |

## 置き場の決め方

`tests/config/` は「設定の層の合成（rules / phases / risk）」、`tests/core/` は
「部品の単体と、速い受入テスト（shellread・glob・lint…）」。`--lint` の検査は `core`、
ルールの読み込みと文の組み立ては `config` に置く。既存のグループ分け
（`.claude/skills/commit/references/test-groups.md`）に合わせ、新しいグループは作らない。

## 確かめ方

- 書いたテストが**落ちる**こと（実装前なので落ちて正しい）を出力で示す
- 既存のテストが、足したぶんを除いて通ったままであること
- 回すのは `core` と `config`（`uv run python -m unittest discover -s tests/core -t .`、
  `-s tests/config -t .`）。この番号では `tests/*` しか触らないので全件は要らない
