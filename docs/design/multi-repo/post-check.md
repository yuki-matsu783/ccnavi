### 11.7 実行後チェック

`git status` をツリーごとに起動する。見るのはワークスペースルートと、そのターンで書き込みのあったプロジェクトとワークツリー。
触ったツリーはセッションの記録（`session/<id>.trees`）が既に持っているので、それを使う。基準（ターンの始まり）と
「もう伝えた」の記録はツリーごとに分ける。差し戻しはそのツリーの git で行う。報告はツリーの名前を頭に付ける。

元リポジトリで見た変更に当てるのは共通層 + そのツリーの層のルールの和、ワークツリーならそのツリーに結び付くチケットの範囲と、
共通層 + 元リポジトリの層。Bash の和は使わない（行き先が分かっているため）。
