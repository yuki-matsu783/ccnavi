# ADR-0083: 初回の吹き出しの案内を拡張の 5 画面すべてに出し、中身が空の画面では案内の間だけ見本を出す

状態: 採用（ADR-0082 の「初回だけ吹き出しの案内を出す」をフェーズ管理画面から 5 画面へ広げる）

追記（2026-09-24）: 案内の入口を、各画面のボタンの並びに混ぜた「？ 案内」から、5 画面ともヘッダ右上に固定した「?」1 文字に改めた（利用者の求め）。

## 状況

2026-09-24。ADR-0082 でフェーズ管理画面に初回だけの吹き出しの案内を足した。利用者は、拡張の全画面
（ボード・ルール設定・リスク管理・フェーズ管理・プロジェクト管理）に同じ案内を求めた。

入れたばかりのワークスペースにはチケットもプロジェクトも無い。ボードは 4 列とも空、プロジェクト管理は
一覧が空で、案内が「カード」「行のメニュー」を指そうにも指す先が無い。利用者は「ツアー中だけ仮チケットを
表示する」ことを求めた。

## 決定

| 決めたこと | なぜ | 採らなかった側 |
|---|---|---|
| 吹き出しの部品（`Tour.tsx`・`Tour.css`）を `src/webview/` へ移し、5 画面で 1 本にする。出し入れは `useTour` にまとめる | 置き場所・焦点・Esc・Tab の扱いを画面ごとに書き直さない | 画面ごとに写す（直すたびに 5 か所） |
| 見たかどうかは今までどおり画面ごと（`tour.<画面>`）。拡張ホストは `ready` で頼み、画面は指す先が出てから始める。ボードは承認のオーバーレイが消えるまで待つ | 1 つ見ただけでほかが消えない（ADR-0082）。オーバーレイの下を指しても見えない | 拡張全体で 1 回 |
| もう一度見る入口は、5 画面ともヘッダ（ツールバー）の右上に小さく固定した「?」1 文字（`TourButton`）。フェーズ管理のヘルプの中の「案内をもう一度見る」はこれに寄せ、ヘルプのボタンは「ヘルプ」とだけ書く | 画面ごとに同じ位置で見つかる。ボタンの並びに混ぜないので、ボードの絞り込みや承認の操作の邪魔にならない（利用者が求めた）。「?」が 2 つ並ぶと見分けにくい | 画面ごとにボタンの並びへ「？ 案内」を混ぜる（初めはそうしたが、位置がばらつき、ボードで邪魔だった） |
| **チケットが 1 枚も無いボードと、プロジェクトが無いプロジェクト管理では、案内の間だけ見本（`core/tour-sample.ts`）を描く。** 見本だと分かる帯を出し、題に「（見本）」を付け、閉じたら消す | 指す先が無いと、案内が画面の要の部品を説明できない。見本は画面の中だけのもので、拡張ホストへは何も送らない（全面の覆いがクリックを受けるので、見本のボタンは押せない） | 雛形のチケットをファイルに書く（利用者のワークスペースを案内が書き換える）。文だけを中ほどに出す（部品の場所が分からない） |
| ボードの見本は実行ファイルの出力と同じ形（`BoardJson`）で書き、`buildBoard` を通す | カードの欄が増えても、見本だけが古くならない | カードの形を直に組む |
| ルール設定の案内はタブを切り替えるが、閉じたら始める前のタブに戻し、途中の切り替えは控えに書かない | ADR-0082 の「案内が利用者の画面を書き換えたまま残らない」と同じ | 切り替えたまま残す |

## 失うもの

- 案内は部品を選択子で指すので、5 画面のどれかで並びを変えるたびに追従が要る（DOM テストが段の題と指す先を見る）
- 見本の中身（題・フェーズ）は実データではないので、仕組みが変わると見本の見せ方が古くなりうる。形は `buildBoard` が見る
- 見本を出すのは「全く無い」ときだけ。絞り込みでカードが全部隠れている、項目やルールが空、のときは見本を出さず、
  指す先の無い段は吹き出しを中ほどに出して文だけを見せる
- 状態が画面ごとに 4 つ増える（`globalState` の `tour.board` など）。消す操作は無い（ヘッダ右上の ? で出せる）

## レビューで直したこと

実装のあと、Sonnet と Opus の敵対的レビューにかけた。

- 承認のオーバーレイの最中に「？ 案内」を押すと、オーバーレイの上に案内が被さった。押した道も、指す先が出るまで待つ
- 覚えていたプロジェクトの絞り込みが効いていると、見本のカードが全部隠れた。見本は絞り込みに当てない
- 閉じたあと焦点が body に移ってしまった（ADR-0082 からあった不具合）。戻す先を最初に描くときに控える
- 案内の最中に中身がエラーや読み込み中へ替わると、吹き出しは消えるのに案内は続いたことになっていて、中身が戻ると
  1 段目から出直した。指す先が消えたら閉じたことにして `tourDone` を返す（フェーズ管理画面も同じ）
- プロジェクト管理の件数（ツールバーと一覧の見出し）が見本で食い違った。見本を出している間はどちらも見本で数える
- 見本のボードが実際の問題の一覧を隠した。問題の一覧は実際のボードのものを出す
