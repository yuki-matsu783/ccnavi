# ADR-0089: 記録は大きさでローテートし、古い記録と終わったセッションの控えをセッション開始で消す。記録に書くコマンドは秘密の形を伏せる

状態: 採用

## 状況

判定の記録（`logs/log.jsonl`）は追記するだけで、どこでも切らず消さなかった。控え（`logs/state/`）も、
自己防衛の控え（`selfguard/`、3 日）と「1 度だけ渡す文」の数え（`once-*` / `approved-*`、3 日）の
ほかは、セッションごとに増える一方だった（issue #149）。

記録にはコマンドの全文が入る。`curl -H 'Authorization: Bearer …'`、`mysql -p<パスワード>`、
`git clone https://oauth2:<トークン>@…` を 1 回打てば、値が平文で残る。

## 決定

| 決めたこと | なぜ | 採らなかった側 |
|---|---|---|
| `log.jsonl` が 10 MB（`CCNAVI_LOG_ROTATE_MB`）を超えたら、同じディレクトリの `log.<日時>.jsonl` へ名前を変える | 名前を変えるだけなら 1 行も捨てない。「記録が無い呼び出し = 動かなかった」の読み方は、ローテートした分も合わせて読めば変わらない。追記中の hook は開いたハンドルのままローテート先へ書き、次の起動から新しい `log.jsonl` を作る | 古い行を切り詰める。まだ保持日数のうちの行を捨てる |
| ローテートした記録は最後に書かれてから 14 日（`CCNAVI_LOG_KEEP_DAYS`）を過ぎたら消す。いま書いている `log.jsonl` は消さない | 消すのは古い分だけに絞る | 件数で残す。記録の多い日が続くと、保持日数のうちの分が消える |
| 控えはセッションを名前に持つもの（`<s>.json`・`<s>.turn.json`・`nudged-<s>.json`・`once-<s>-*`・`approved-<s>-*`・`subagent-<s>-*.bounced`・`selfguard/<s>/`）だけを、セッションごとにまとめて、どれも 14 日（`CCNAVI_STATE_KEEP_DAYS`）書かれていなければ消す。いま始まったセッションは日付を見ずに残す | Claude Code はセッションの終わりを hook に知らせない。動いているセッションはターンの基準をプロンプトのたびに、自己防衛の控えを実行前の判定のたびに書き直すので、どれかが必ず新しい。1 本ずつ日付で見ると、長く続くセッションの、1 度しか書かない控え（差し戻しの印など）が消える | ファイルごとに日付で見る。上の理由 |
| セッションを名前に持たないもの（`review-*.md`・`risk-judge-*.md`・`aside/`・`selfguard/store/`）は消さない | チケットとレビューの寿命で使われるか、戻したときに退避した利用者のファイルそのもの。セッションの日付では決められない | 控えの置き場を丸ごと日付で掃く |
| 走らせるのはセッション開始（`SessionStart`）と、人が端末から打つ `ccnavi --prune`。`--preview` なら動かさずに並べる。実行前の判定（`PreToolUse`）では走らせない | 重い仕事はセッションに 1 度の場所へ置く（ADR-0003 と同じ理由）。開始では失敗しても止めず、標準エラーに出し、動かした数を記録の `detail`（`pruned rotated=… logs=… state=…`）に残す | 記録を書くたびに大きさを見てローテートする。判定の経路に置き場の操作が入る |
| `--prune`（`--preview` なし）は端末を求める（`--approve` と同じ門）。加えて、エージェントがシェルから打つ形はチケット制御に依らず組み込みの deny（`DENY_RECORDS_PRUNE`）で止める | しきい値は環境変数で動くので、エージェントが `CCNAVI_LOG_KEEP_DAYS=0` を前に並べて打てば自分の呼び出しの記録を消せる。端末要求だけでは、擬似端末（`script -qc '…' /dev/null`）や、チケット制御を切ったワークスペースで端末要求を切る変数を並べる形で抜けられる | 誰でも打てる形。上の穴 |
| しきい値は 0（その段を止める）のほか、1 MB・1 日より小さい値と有限でない値（`inf`・`nan`）を受けず、既定で動いて報告に出す | 0 に近づけるだけで保持日数のうちの記録が消える。`inf` はローテートの大きさを整数にするところで落ちる | 読めた値をそのまま使う |
| `<s>.json` と読むのは UUID の形の名前だけ。`denied-<s>.json`（repeat）はセッションの控えとして読む。知らない名前のファイルと、リンクになった `logs/state`・`selfguard/` には触らない | `.+\.json` で読むと、置き場の別のファイル（`package.json` など）や、動いているセッションの `denied-` を別のセッションと読んで消す。リンクを辿ると置き場の外を消す | 置き場の json を全部セッションの控えと読む |
| ローテート先は `O_EXCL` で空のファイルを作って押さえてから、`os.replace` で名前を変える | 同じ秒に始まった 2 つのセッションが同じ名前を選ぶと、後の側が先にローテートした記録を上書きする | 名前を決めてから有無を見る。見てから変えるまでのあいだが空く |
| 記録と控えの置き場は `Write` / `Edit` / `NotebookEdit` からも組み込みの deny（`builtin-guard-records`）で止める。動かした置き場（`CCNAVI_LOG` / `CCNAVI_STATE`）にも当てる | シェルの側だけ止めると、`denied-<s>.json` や記録を名指しのツールで書き換えられる。シェルの側の文面は「Write / Edit でも拒否される場所」と言っている | シェルの側だけで守る |
| ローテートした記録（`logs/log.<…>.jsonl`）も、組み込みのシェル書き込みの deny で守る | 判定は読まないが、`log.jsonl` と同じく「動かなかった」を読む元。消すのは上の 2 つの経路だけにする | `log.jsonl` だけを守る。ローテートした時点で守りが外れる |
| 記録の `subject`・`unwrapped`・`detail` は、書く直前に秘密の形を伏せる（`ccnavi/redact.py`）。短い値（18 字未満）は全部、長い値は頭 6 字と尻 4 字を残す。判定は伏せる前の文字列で下す。`subject`・`unwrapped` は伏せる前にも 4000 字で切り、どの形も長さにほぼ比例する手間で当てる。伏せる処理が何で落ちても、その欄には平文の代わりに `[ccnavi: 秘密を伏せる処理が失敗したため、この欄の中身は記録していません]` を書き、hook は 0 で終わる（記録は判定を出した後に書くので、ここで落ちると出した deny が捨てられる） | 判定の側で伏せると、伏せた形にルールを当てることになる。頭と尻を残せば、同じ値が繰り返し出ているか、どの種類のトークンかを記録から見分けられる | 秘密らしいコマンドの行をまるごと落とす。「記録が無い = 動かなかった」が崩れる |

伏せる形: `Authorization:` / `Cookie:` ヘッダの値、`Bearer <値>`、名前が `token` / `password` / `secret` /
`secret_key` / `_pwd` / `api_key` / `cookie` などで終わる `名前=値` / `名前: 値`、`--password <値>` などのフラグ、
AWS の `AKIA…`、GitHub の `ghp_…` / `github_pat_…`、GitLab の `glpat-…`、Slack の `xox?-…`、`sk-…`（`sk-ant-…`・
`sk-proj-…`）、Stripe の `sk_live_…` / `rk_live_…`、Google の `AIza…`、npm の `npm_…`、JWT、URL の `user:<値>@`
（値に `@` があればホストの手前の最後の `@` まで）、mysql 系の `-p<値>`、curl の `-u user:<値>` と `-b` / `--cookie`、
sshpass の `-p`、docker login の `-p`、redis-cli の `-a`、`aws configure set aws_secret_access_key <値>`、秘密鍵の本文。
コマンドを限るフラグは、そのコマンドの中でだけ読む（`mkdir -p`・`ssh -p 22`・`ls -a` は伏せない）。
`$VAR` のように変数を指すだけの値は伏せない。

## 得たもの・失ったもの

- 得たもの: 記録と控えの置き場が際限なく増えない。記録に残る秘密の値が減る
- 失ったもの: **14 日より前の記録は残らない。** 長い期間の集計が要るなら、しきい値を延ばすか、消える前に
  自分で写す。README の `jq` の例は `logs/log*.jsonl` をまとめて読む形にしないと、ローテートした分を数え落とす
- 失ったもの: 14 日何も書かずに置いたセッションを再開すると、控えが消えている。すでに伝えた変更をもう 1 度
  報告し、`finish` の促しと差し戻しをもう 1 度出しうる。どれも言い直すだけで、止める側は緩まない
- 失ったもの: 伏せ方は形で見るので、取りこぼしも、秘密でないものを伏せることもある。後者は記録が読みにくく
  なるだけで、判定は変わらない
- 失ったもの: 端末を持たない実行環境では `--prune` を打てない（`--preview` は打てる）。セッション開始の後始末は
  変わらず走る。エージェントの Bash からは、`--preview` を `--prune` の隣に置かない形（`--prune --json --preview` など）も
  止まる
- 失ったもの: UUID の形でないセッションの `<s>.json` は消えない。名前の長すぎる秘密の名前（頭が 64 字を超える）と、
  伏せる前の 4000 字より後ろの値は伏せない（後者は記録の 1000 字の上限で切られて残らない）
- 失ったもの: 設計書の置き場の表にある `logs/session/` は、いまの実装では書かれていないので後始末の対象に
  入れていない。git のラッパースクリプトの記録（`logs/git-*.log`）は `ccnavi-git.sh` が件数で切っている
  （`CCNAVI_GIT_KEEP_LOGS`）ので、ここでは触らない

## 採らなかった案

- 記録を日付ごとのファイルに分けて書く。書く側の経路が変わり、`CCNAVI_LOG` の意味（1 本のファイル）が変わる
- 常駐して定期的に掃く。ADR-0003
