# ADR-0071: 報告するのは deny と ask と範囲外、戻すのは deny だけ

状態: 採用

## 状況

実行後の監視は、保護領域をルールファイルの `deny` と `ask` から導く（ADR-0017）。承認された
チケットの範囲の外も、同じ面が咎める。戻す働き（`CCNAVI_RESTORE_IF_DENY`、既定 enable、ADR-0019）は、
そのうちどれを戻すのかを分けていなかった。**検知したものを全部戻していた。**

3 つは宣言していることが違う。

- `deny` は「書くな」
- `ask` は「人が 1 度見る場所」。見た結果が「よい」であることもある
- チケットの範囲の外は、ルールファイルが何も言っていない場所。咎めているルール
  （`post.TICKET_SCOPE_RULE`）は出所を示すための作りもので、ルールファイルには無い

そのため、既定の設定のまま次のことが起きていた。人が `ask` の確認に「はい」と答えて Write した
編集が、直後の `PostToolUse` でコミット済みの内容へ戻る。ビルドが範囲の外へ置いた出力が、
毎回 `state/aside/<日時>/` へ移される。環境変数の名前は `CCNAVI_RESTORE_IF_DENY` で、
`requirements.md` の REQ-PST-05 も「検知した変更を元に戻し」としか書いていなかったので、
名前も説明も実装も三者三様だった。2026-09-22。

## 決定

- **戻すのは `deny` と宣言された場所だけ**（`post._restorable`）。当たったルールの `decision` が
  `deny` のものを 1 本でも含む finding に限る
- **報告する範囲は変えない。** `post._guarding` は `deny` と `ask` の両方を返したままにし、
  チケットの範囲の外も咎めたまま
- **戻さなかった 1 件には、戻さない理由と次の一手を添える**（`not-restored:` の行）。
  `ask` のルールは文面を持てない（lint が error にする。ADR-0017）ので、ここで言わないと
  誰も言わない。手順だけを渡すと、受け取ったエージェントには「自分で戻せ」としか読めない
- **戻さなかった 1 件は控え（`seen`）に入る。** 戻していないのでファイルは汚れたままで、
  `git status` は次の呼び出しでも同じ 1 件を返す。呼び出しごとの報告はセッションで 1 度きりにし、
  その後はターンの終わりの報告が人に見せる
- 要件（REQ-PST-01 / REQ-PST-05）と、README・設計書の文面を実装に合わせる

## 理由

**名前と説明が言っているとおりにした。** 逆向き（実装に合わせて説明を直す）だと「ルールが
言っていない場所も戻す」と書くことになる。それは仕様として通らない。

**`ask` を保護領域から外す道は採らなかった。** 実行前の判定はツール呼び出しの引数しか見ないので、
`ask` の確認が出るのは Write / Edit で書いたときだけ。シェル・ビルド・スクリプトが内部で開いた
ファイルは引数に現れず、誰にも確認が出ないまま通る。`_guarding` から `ask` を外すと、その経路に
ついて言う場所が 1 つも無くなる。論点は「報告するか」ではなく「戻すか」だった。

**門を 2 つに割る道（`deny` 用と範囲外用）も採らなかった。** 環境変数が 1 本増え、しかも
いまある門のうち 2 本が `--lint` に声を持っていない（ADR-0072 と同じ時期に直した）状態で、
声を持たない門をもう 1 本増やす形になる。

## 得たもの

- **既定の設定で、頼んでいないファイル操作が起きない。** 人が確認に答えた編集が消えない
- **名前・説明・実装が揃った。** `CCNAVI_RESTORE_IF_DENY` が言うとおりの対象になった
- 報告は 1 件も減っていない。差し戻し（終了コード 2）も減っていない

## 代償

- **`deny` と書いていない保護領域は、自動では戻らない。** シェルやビルドが `ask` の場所を
  書いたぶんは、報告は出るが片付けるのは人かエージェントになる
- **範囲外の生成物を自動で片付ける経路が無くなった。** `SubagentStop` は範囲外を見つけると
  1 回だけ差し戻すが、止めて伝えるだけでファイルは戻さない
- **`CCNAVI_RESTORE_IF_DENY=disable` では `not-restored:` の行が出ない。** その設定では
  `deny` も戻らないので、理由が「ask だから」ではなく「切ってあるから」になる。切った人は
  承知しているはずだが、`ask` の場所を自分で戻すな、という断りはそこには届かない
