# ADR-0112: 索引を ccnavi-index.jsonl にし、無視の行が無いツリーには .gitignore に足して索引の対象にする

状態: 採用（2026-10-11 にユーザが決めた）

## 状況

`--docs` の索引は `index.jsonl` という名前で、そのリポジトリの `.gitignore` に `**/index.jsonl` があるときだけ書かれた。
ccnavi は他人のリポジトリの `.gitignore` を書き換えない設計だったので、無視の行が無いプロジェクトは索引の対象外になり、
`--docs` でそのプロジェクトの md を引けなかった。`index.jsonl` は他のツールの同名ファイルと被りうる名前でもあった。

## 決定

| 決めたこと | なぜ | 採らなかった側 |
|---|---|---|
| 索引のファイル名を `ccnavi-index.jsonl` にする | 他のツールの同名ファイルと被らない。ccnavi のものだと名前で分かる | `index.jsonl` のまま、ccnavi の形かどうかの判定だけで守る |
| 無視の行が無い git ツリー（ワークスペースもプロジェクトも）は、索引を書く前に、そのツリーのルートの `.gitignore` に `**/ccnavi-index.jsonl` を 1 行だけ足す。ファイルが無ければ作る。既存の行は変えない | プロジェクトの md も `--docs` で引けるようにする。「git が無視しているときだけ書く」という、作業ツリーを汚さない条件は変えない | `.git/info/exclude` に足す（差分は残らないが、別の機械に伝わらず、`git status` の外で効くので見えにくい）。足さずに対象外のままにする |
| `!` で `ccnavi-index.jsonl` を否定する行（`!*.jsonl` のような広い行を含む）があるツリーには足さない。足せなかった・足しても無視されない（追跡されている）ツリーだけを、従来どおり「索引の対象外」として案内する | ユーザが索引を追跡すると決めている場合に、その決定を後ろの行で無効にしない | 否定の行の後ろに足す。git は後ろの行を優先するので、ユーザの否定を打ち消す |
| 足したことは、`--docs` の標準エラーと SessionStart の案内に、どのツリーの `.gitignore` かを名指しして出す | プロジェクトの `.gitignore` に未コミットの差分が残る。`worktree remove` と `integrate` の「未コミットの変更」判定にかかるので、ユーザが気づけるようにする | 黙って足す |
| 足すのは、書き込める状態（refresh）のときだけ。`--no-refresh` と、期限の残りが少ない SessionStart は足さない | 読むだけの経路でリポジトリの設定を書き換えない | どの経路でも足す |
| `scripts/ccnavi-setup.sh` とワークスペースの `.gitignore` の行を `ccnavi-index.jsonl` にする。導入スクリプトは従来どおり `projects/` の下には足さない（そこは `--docs` が足す） | 導入と `--docs` で名前をそろえる | 古い名前の行を残す |

## 得たもの・失ったもの

- 得たもの: プロジェクトの md も、無視の設定を手で直さずに `--docs` で引ける。同名ファイルとの衝突が無くなる
- 失ったもの: 「ccnavi は他人のリポジトリの `.gitignore` を書き換えない」という約束。追記は 1 行だけで、否定の行があれば足さない
- 失ったもの: 追記したプロジェクトの `.gitignore` が未コミットで残る。名指しの案内で気づかせ、コミットはそのプロジェクトのチケットの中で行う
