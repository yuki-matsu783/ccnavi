# ADR-0097: ELI5 の置き場と依頼の検査を厳しくする（綴りの `\` と大文字小文字、名前の字、モード、互換の版）

状態: 採用（ADR-0095 の置き場の絞り込み・名前・案内の綴りと、ADR-0096 の除外の綴りの読み方を改める）

## 状況

ADR-0095・0096 の変更に敵対的レビューが入り、次の指摘が出た（2026-10-01）。ユーザは「判定を厳しくする側ですべて直す」と決めた。

| 重さ | 指摘 |
|---|---|
| high（再現済み） | `ticket.is_eli5_place` が `\` を `/` に読み替えてから見るので、Linux / macOS でツリーの直下に `wip\eli5\evil.py` という名前の 1 ファイルを置くと、実行前の判定・実行後の監視・SubagentStop（`phase.scope_findings` が判定の前に読み替えていた）の 3 か所で範囲を逃れる。`git ls-files -- wip` にも出ないので、`ready` の片付けにも掛からない |
| medium | 標準出力の crit の行と依頼文の 1 行にシェル注入の余地。相対パスはバッククォートの中に生で入り、ツリーのパスは `'` をエスケープしていなかった |
| medium（推測） | 大文字小文字を区別しない FS で `WIP/eli5/` を先に作ると、範囲の除外は `wip/eli5/` として通るのに、git には `WIP/...` で入り、`ready` の検査（区別する）で残る |
| low | sh の置き場の検査が `wip/*` で、`wip/eli5/` より広い |
| low | `wip/eli5/` の除外がチケットの `deny` と全面停止（`LIMIT_BLOCKED`）より先に適用される |
| low | ELI5 がシンボリックリンクでも通る |
| low | 文書: 古い ADR の状態の行に置き換えた側の番号が無い。glab での crit push が未確認と書いていない。手元が古いと行がずれる |
| low | 互換の版を上げていない |

## 決定

| 決めたこと | なぜ | 採らなかった側 |
|---|---|---|
| 置き場の判定（`is_eli5_place`・`_under`（チケットの置き場）・`is_scratch_place`）は、パスの `\` を `/` に読み替えない。`phase.scope_findings` の読み替えも消す（範囲の照合にも影響する） | 呼び手が渡すのは `tree.relative`（`os.sep` を `/` に直した綴り）か git の綴りで、どちらも区切りは `/`。Windows の区切りは `tree.relative` が直すので、ここで読み替える理由が無い。読み替えると Linux / macOS で `\` を含む名前の 1 ファイルが置き場や範囲の中に見える。**チケットの置き場（`wip\proposals\todo\x.py`）と下書きの置き場（`scratchpad\x.py`、実行前の判定だけ）にも同じ穴があった**ので同じく直した。`scope_findings` の読み替えは `src\x.py` を `src/*` の中と読ませていた（実行前の判定は読み替えていないので、実行前は止めて終了時は通す食い違いがあった） | ELI5 だけ直す。同じ形の穴が残る |
| `ready` の前提（`_merge_problems`）は、追跡されているファイル全部を `-z` で読み、大文字小文字を問わず `wip` の下か、名前が `wip\` で始まるものを残りとして止める。消し方は実際の先頭の名前で案内する | 区別しない FS で `WIP/eli5/` を先に作った形と、`\` を含む名前の形を、成果物に残さない。pathspec の `:(icase)` は git 1.8.4 から使えるが、`\` を含む名前は拾えないので、全部を読んで絞った。git の版にも依らない | `:(icase)wip` の pathspec |
| 範囲の除外と「動いた」の見分けは、今までどおり大文字小文字を区別する | 区別しない側に広げると除外が広がる。`WIP/eli5/` を通してしまう抜けは `ready` が拾う | 区別しない |
| sh の置き場の検査を `wip/eli5/*` に絞る | 除外（`wip/eli5/`）と依頼の検査の置き場を揃える。`wip/design/x.html` を ELI5 にさせない | `wip/*` のまま |
| ELI5 のツリーのルートからの相対パスは `[A-Za-z0-9._/-]` だけを許し、外れたら前提の未充足として全件を挙げて止める。C ロケールの `tr -d` で許す字を消し、印だけが残るかで見る（改行も 1 字として残る） | 相対パスは依頼文とユーザが打つ crit の行にそのまま入る。`'`・`$`・バッククォート・空白・改行を通すと、打ったユーザのシェルで別のコマンドになる綴りを置ける。日本語も止まるが、既定の名前（`phase-<N>.html`）で足りる | 包んでエスケープする。依頼文の Markdown とユーザのシェルの両方で正しくエスケープする綴りが要り、読み違いの余地が残る |
| ツリーの絶対パスは、案内の `cd` でいつも `'…'` で包み、中の `'` は `'\''` に置き換える | ユーザの置き場なので字を絞れない | 字を絞る。置き場によっては依頼が出せなくなる |
| HEAD でのモード（`git ls-tree HEAD`）が 100644 であることを求める。シンボリックリンク（120000）・実行の印付き（100755）・submodule は止める | リンクは指す先が差分に無く、crit で見るものと差分が食い違う。100755 は害は小さいが、普通の HTML に要らない印で、ユーザの「厳しくする側」の決定に合わせて止めた | 100755 は通す |
| 互換の版（`COMPAT`・`CCNAVI_COMPAT`・`EXTENSION_COMPAT`）を 1 から 2 に上げる | hook の案内（実行ファイル）と sh の `request` の受け付ける形が ADR-0094〜0097 で変わり、古い sh と新しい実行ファイル（またはその逆）では案内どおりに打っても止まる。`tell_skew` と `--lint` と拡張の通知で食い違いを知らせる。Chrome 拡張は版の違う統合先では書く操作を出さない（ADR-0093 の 7.3）ので、統合先の sh を新しくするまで「始める」などが止まる | 上げない。食い違いが知らされない |
| Chrome 拡張の試験は互換の版を `ccnavi/version.py` から読む（`test/helpers/compat.ts`）。違う版を試す箇所は `COMPAT + 1` | 版を上げるたびに試験の数字を直さずに済む | 数字を 2 に書き換える |

`wip/eli5/` の除外が `deny` と全面停止より先に適用されること（low の指摘）は、コードを変えず代償として下に書く。

## 得たもの・失ったもの

- 得たもの: `\` を含む名前の 1 ファイルで範囲を逃れる手段が、ELI5・チケットの置き場・下書きの置き場・範囲の照合（SubagentStop）の全部で無くなる
- 得たもの: 依頼文と案内の行に、打ったユーザのシェルで実行される綴りが入らない
- 得たもの: `WIP/` や `wip\…` の残りが `ready` で止まり、成果物に残らない
- 失ったもの: **`wip/eli5/` の除外は、チケットの `deny` と全面停止（`LIMIT_BLOCKED`）より先に適用される。** `is_unscoped` が範囲の判定
  （`scope_verdict`）より前にあるので、チケットが `deny: [wip/eli5/*]` と書いても、チケットが信じられず全部の書き込みを止める
  状態でも、`wip/eli5/` の下には書ける。チケットの置き場と `scratchpad/` も同じ形で先に適用される。`wip/` は `ready` の前に消えるので
  既定のブランチには届かないが、レビューの間はマージリクエストの差分に載る
- 失ったもの: ELI5 の名前に日本語や空白を使えない
- 失ったもの: 実行の印付きの HTML（100755）も止まる。`core.fileMode` が真の環境で印を付けてしまったら外してコミットし直す
- 失ったもの: `\` を含む名前のファイルは、Linux / macOS でも置き場として扱われない（意図して置いた例は無いはず）
- 失ったもの: `ready` は追跡されているファイル全部を読む。大きなリポジトリでは 1 回ぶん遅くなる
- 失ったもの: 互換の版が 2 になったので、古い sh・古い拡張・古い Chrome 拡張と組み合わせると知らせが出る（Chrome は書く操作を出さない）。
  配り直すまで続く

## 採らなかった案

- **除外を `deny` と全面停止のあとに置く。** 判定の順を変えるとチケットの置き場と `scratchpad/` の扱いにも及び、影響が読み切れない。代償として書くに留めた
- **ELI5 の名前をエスケープして通す。** 上の表のとおり
