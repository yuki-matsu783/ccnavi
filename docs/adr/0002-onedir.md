# ADR-0002: 配布は PyInstaller の onedir にする

状態: 採用

## 状況

hook として登録する実行ファイルは、使う側にランタイムの導入を求めない形で配る（REQ-HKS-04）。
PyInstaller には 1 ファイルに固める onefile と、実行ファイルと同梱物のフォルダにする onedir がある。

## 決定

onedir で組み立て、`dist/ccnavi/` のフォルダごと配る。要件の「単一の実行ファイル」は
「実行ファイルとその同梱物 1 フォルダ」に書き換えた。

## 理由

onefile は起動のたびにランタイムを一時ディレクトリへ展開するので、実測で 1 呼び出しあたり
1.0〜1.5 秒かかった。hook はすべてのツール呼び出しで走るから、それが全部に乗る。
onedir は約 220 ms で、Go より 80 ms ほど遅いだけ。

| 形式 | 1 呼び出しあたり | 配布物 |
|---|---|---|
| onedir | 約 220 ms | 17 MB のフォルダ |
| onefile | 1000〜1500 ms | 7 MB の 1 ファイル |

## 得たもの・失ったもの

- 得たもの: 起動の遅さが期限（3 秒）を圧迫しない
- 失ったもの: 配布物が 1 ファイルでなくなり、`_internal/` を一緒に配る。前の版の同梱物が
  残ると新しい実行ファイルがそれを掴むので、配るときは先に消す（導入スクリプトが行う）
- 失ったもの: Windows は実行中の実行ファイルを上書きできない。`build.py` は別の場所に組んで
  古いほうを `.old` に退避してから入れ替え、失敗しても数回やり直す

## 採らなかった案

- onefile。上の実測のとおり
- PyInstaller に `ccnavi/__main__.py` を直接渡す。パッケージの外の素のスクリプトとして
  走らせるので相対 import が解決できない。絶対 import で書いた `main.py` をルートに置いて渡す
