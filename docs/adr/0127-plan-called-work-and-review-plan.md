# ADR-0127: 親の計画とフィードバック計画をまとめて「作業・レビュー計画」と呼び、ワークフローの呼び名をやめる

状態: 採用（2026-10-12 にユーザが決めた。ADR-0078・ADR-0109 の「ワークフロー」「ワークフロー編集タブ」の呼び名を改める。ほかの決定はそのまま。ユーザに見える文言と文書を同じ日に直接作業で改めた）

## 状況

ADR-0109 より前、`workflow:` は承認で計算して承認済みチケットに写す欄だった。ADR-0109 でこの欄をなくし、順序は親の提案の `plan:` の項の `after` だけが持つことにした。`workflow:` が書かれていれば `--agree`・`--lint`・判定が error にする。

欄が消えたあとも、「ワークフロー」という語は次の場所に残った。

- VS Code 拡張の画面名（「ワークフロー編集タブ」、親の提案のカードの「ワークフロー」、承認のオーバーレイの「ワークフローを編集」、タブの題「ccnavi ワークフロー: <親>」）
- `--plan-order`・承認・取り下げの案内文、設計書、拡張の要件書

この語は一般語で、画面が何を編集するのかが名前から読めない。画面が引き直すのは、親の計画の項どうしの先行（`after`）である。ユーザがレビューする位置（`review`、延期先）は図に出して見せるだけで、画面では編集しない。編集の対象は `plan:` と `feedback:` の欄の項なのに、名前が欄と対応せず、死んだ `workflow:` 欄とも混同される。

## 決定

| 決めたこと | なぜ | 採らなかった側 |
|---|---|---|
| ユーザに見える呼び名を「**作業・レビュー計画**」にする。親の `plan:`（全体計画）と `feedback:`（フィードバック計画）の両方を指す | 計画の項が作業とレビューの位置を持つことが名前から読める。欄の `plan:`・`feedback:` と一対一に対応する | 「計画」だけを正式名にする（`plan:` だけを指す既存の使い方と区別できない）。「ワークフロー」のまま（上の状況） |
| 短くするときは「**計画**」と書いてよい。ただし既存の文書では「計画」が `plan:` だけを指すことが多い（「親は計画を必ず持つ」など）ので、短縮形がどちらを指すかは文脈で読む。両方を指すことを言いたいときは正式名で書く。画面・タブの名前は「**計画編集**」、押すボタンは動詞の形にそろえる（例: 「計画編集タブ」、タブの題「ccnavi 計画編集: <親>」、カードの「計画編集」、オーバーレイの「計画を編集」） | 「作業・レビュー計画」は長く、タブの題・ボタン・通知に収まらない。短縮形の曖昧さは、既存の使い方を書き換えないことと引き換えに受け入れる | 常に「作業・レビュー計画」と書く。既存の「計画」をすべて `plan:` に書き換えて「計画」を全体の呼び名にする |
| 内部の識別子は変えない（`workflow-panel.ts`、`Workflow` クラス、コマンド ID `ccnaviBoard.openWorkflow`、ディレクトリ `webview/workflow/`、案内の定義 `tours/workflow.yml` など） | 利用者のキーバインドや設定が参照するコマンド ID を壊さない。名前だけの変更で差分が大きくなる。画面に出ず、コード内の語と画面の語が違うことの害は、docstring に古い呼び名を書けば足りる | 識別子もそろえて改める |
| 過去の ADR（0078・0109 など）の本文は直さない。ADR-0109 の状態の行と、`docs/adr/README.md` の該当行に、呼び名を ADR-0127 が改めたと書き添える | ADR は当時の判断の記録で、消さない | 本文の語を置き換える |
| 欄 `workflow:` は ADR-0109 のまま廃止。ADR-0127 は欄に手を入れない | 呼び名だけの変更で、判定は変わらない | — |
| `.ccnavi/docs/terms.md` に「作業・レビュー計画」の定義を足す | 文書と案内で同じ語を使うための置き場 | — |

## 得たもの・失ったもの

- 得たもの: 画面名から、何を決める画面かが読める。欄 `plan:`・`feedback:` と画面の呼び名が対応する。死んだ `workflow:` 欄との混同が減る
- 失ったもの: コードの識別子（`workflow-*`）と画面の呼び名が食い違う。過去の ADR を読むと古い呼び名が出てくる（`terms.md` と各 docstring に別名を書いて補う）
