# ADR-0048: ルールの層は、パスを持つツールは行き先で、持たないツールは全部の和で選ぶ

状態: 採用

## 状況

ルールは 3 つの層（共通層、自身の層、プロジェクトの層）から来る（設計 §11.4）。1 回の判定にどの層を足すかは、
ツールごとに決める必要がある。

層を選ぶ側（`ruleload.rules_for`）が決めていたのは、Read・Write・Edit・NotebookEdit（行き先の層）と Bash・PowerShell（全部の和）
だけで、それ以外のツールは共通層だけで判定していた。そのため次の 2 つが起きていた。

- 自身の層やプロジェクトの層に `match: WebFetch` / `Skill` / `Agent` / `Grep` / `Glob` のルールを書いても一度も当たらず、
  `--lint` も知らせない。書いた人は効いていると思い込む
- 判定側（`judge.PATH_TOOLS`）は Grep・Glob をパスを持つツールとして扱う（探す場所を省けば `cwd`）のに、層を選ぶ側の一覧には
  入っていない。`lib` の層で `*/secrets*` を deny にすると、Read は止まり、同じ場所を Grep・Glob で探すと止まらない

## 決定

**ツールを、行き先のパスを持つかどうかで 2 つに分ける。**

| ツール | 足す層 |
|---|---|
| パスを持つ: Read / Grep / Glob / Write / Edit / NotebookEdit | 共通層 + 行き先のツリーの層（プロジェクトならその層、ワークスペースのツリーなら自身の層） |
| パスを持たない: Bash / PowerShell / WebFetch / Skill / Agent | 共通層 + 自身の層 + 全プロジェクトの層（和） |

- 行き先は `judge.subject_of` が解いたパス。Grep・Glob が探す場所を省いたときは `cwd`
- パスを持つツールの一覧は `ruleload.PATH_TOOLS` の 1 か所に置き、判定側（`judge.PATH_TOOLS`）はそれを使う
- 一覧に無いツールは、ルールを当てる対象を持つ限り和で判定する

## 理由

**パスを持つツールは、どのプロジェクトの呼び出しかが行き先で 1 つに決まる。** 決まるなら、そのプロジェクトのルールだけを当てる。
Read と Grep・Glob は同じ場所を読むので、同じ層で判定しないと、読み方を変えるだけで守りが外れる。

**パスを持たないツールは、どのプロジェクトの呼び出しかを決める材料を持たない。** Bash は `cd` を挟めば `cwd` の外に届き、
WebFetch・Skill・Agent は行き先のパスそのものを持たない。当てずに和を取れば、`deny` と `ask` は増える側に倒れる（ADR-0033 と同じ理屈）。

**共通層だけで判定すると、層に書いたルールが黙って効かない。** 効かないルールを書ける形は、足したつもりで何も止めていない 1 行を生む。

## 得たもの・失ったもの

- 得たもの: 自身の層とプロジェクトの層に書いた WebFetch・Skill・Agent・Grep・Glob のルールが効く
- 得たもの: Read・Grep・Glob で、同じ場所の守りが揃う
- 失ったもの: パスを持たないツールで `allow` を共有する。プロジェクト A の層で WebFetch や Skill を `allow` にすると、プロジェクト B の作業にも効く。
  共通層の `ask` は層の `allow` より先に当たるので緩まない
- 失ったもの: Grep・Glob でも、行き先のプロジェクトの `allow` が効くようになり、許す範囲がそのツリーの中で広がる
- 失ったもの: Grep・Glob はディレクトリを再帰的に探すが、層は探し始める場所の 1 つで選ぶ。ワークスペースルートから探すと、中のプロジェクトの層は足さない

## 採らなかった案

| 案 | 落とした理由 |
|---|---|
| 今のまま、パスを持たないツールは共通層だけにし、層に書いたルールを `--lint` が warn で知らせる | 層で WebFetch などを制御する道が無いまま残る |
| パスを持たないツールは全層の `deny`・`ask` だけを足し、`allow` は共通層だけにする | 緩む方向に倒れないが、Bash と扱いが違い、「allow だけ効かない」という規則が 1 つ増える |
| Grep・Glob は共通層だけのまま | Read と守りが食い違ったまま残る |
