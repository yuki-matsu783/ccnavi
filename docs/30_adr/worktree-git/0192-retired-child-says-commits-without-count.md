# ADR-0192: 取り消した子のブランチの一覧に、親に無いコミットの数を添えない

状態: 採用

## 状況

ADR-0138 は、親を閉じるときに取り消した子のブランチを一覧にし、親に無いコミットの数を添えてユーザに見せると決めた。数は `rev-list --count` で数えていたが、消してよいかの判定には使っていなかった。祖先かどうかは別に確かめている。

## 決定

数を数えるのをやめる。子の先頭が親の祖先でないときだけ「（親に入っていないコミットがある）」と添える。祖先なら何も添えない。

## 得たもの・失ったもの

- git の呼び出しが 1 つ減り、0 件のときに「0 件」と出す分岐が無くなる
- 何件あるかは一覧に出ない。知りたいときは `git log` で確かめる
- git が失敗したときは「祖先でない」扱いになり、添え書きが出る。消す側には倒れない
