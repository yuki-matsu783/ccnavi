# ADR-0129: 置き場を wip/handoff/ と ルート直下の scratchpad/ の 2 つに分ける

状態: 採用（ユーザが決めた。ADR-0110 の「置き場をひとつにする」を改める。`wip/` に置く側の扱いは ADR-0110 のまま）

## 状況

ADR-0110 は下書きの置き場を追跡される `wip/scratchpad/` に一本化し、ワークツリー直下の無視される `scratchpad/` を廃止した。
その結果、次の 2 つの用途が 1 か所に混ざった。

- チケット作業で、保護対象を直したコピーなどを MR と一緒にユーザへ見せる（追跡され、履歴に残ってよい）
- 直接作業で、一時的にユーザへ見せる物や、コミットしたくない物（機密、巨大な出力）を置く

後者は追跡される置き場に置けず、置き場が「未定」のまま残っていた。また名前の `scratchpad` は、2 つ目の用途を表すのにふさわしい。

## 決定

| 決めたこと | なぜ | 採らなかった側 |
|---|---|---|
| `wip/scratchpad/` を `wip/handoff/` に改名する。扱い（追跡、`integrate` が外す、`ready` が消す、チケットの範囲を適用しない、`workspace-root` の例外）は変えない | 置く物は「ユーザに渡す物」なので、名前で用途が分かる。`staging` は `staging` フェーズ（`wip/design/scripts/`）と衝突する | `wip/staging/`。フェーズの語と混ざる |
| ワークスペースルート直下に `scratchpad/` を足し、`.gitignore` の `/scratchpad`（末尾の `/` なし。ディレクトリにも symlink にもヒットする）で追跡から外す。`workspace-root` のルールの例外にする | 直接作業の一時的な物とコミットしたくない物の置き場ができる。追跡されないので、MR にも履歴にも載らない | ワークツリー直下の `scratchpad/`。ワークツリーごと消え、メインの `.gitignore` が届かない |
| 置き場の場所はユーザのチェックアウトのワークスペースルートの 1 か所。ワークツリーの中からも、そこへ書く | ワークツリーを片付けても残り、ユーザが開く場所が 1 つで済む | ワークツリーごとに持つ |
| ルート直下の `scratchpad/` にはチケットの範囲を適用しない（ユーザのチェックアウトは範囲を持たない）。ccnavi は消さない | 判定を足さずに済む。無視されるので、片付けの検査にも実行後チェックにも出ない | 範囲の例外を足す |
| レビュー依頼の末尾の一文を「`wip/handoff/` 配下はユーザに渡す差し替え用のコピーなどで、レビューの対象外。integrate で消える。」にする | 置く物の説明が実態に合う。対象外にするのは変えない | 一文を消す。差分に載ったコピーをレビュアーが読んでしまう |
| 過去の ADR と設計書の `wip/scratchpad` を、今回に限って `wip/handoff` に書き換える | 名前を検索して辿れるように。ADR-0110 のファイル名も改めた | 当時の事実として残す |

差し込みの `{{scratch}}`（`.ccnavi/CCNAVI.md` の置き場の名前）は、これまで `wip/scratchpad` を指していたが、
`scratchpad` のルート直下の絶対パスを指すように変えた。追跡される置き場は新しい `{{handoff}}` に移った。
絶対パスにしたのは、ワークツリーの中で相対の `scratchpad/` に書くと、ユーザのチェックアウトのルートではなくワークツリー直下に作ってしまうため。

## 得たもの・失ったもの

- 得たもの: 渡す物と使い捨ての物が別の場所に分かれる。コミットしたくない物の置き場が決まる
- 失ったもの: 置き場がまた 2 つになる。ADR-0110 が避けた混乱が戻る余地がある（使い分けは `.ccnavi/docs/scratchpad.md` の表に書いた）
- 失ったもの: ルート直下の `scratchpad/` は ccnavi が消さない。片付けは作業した人の仕事になる
- 失ったもの: ルールの判定は大文字小文字を区別しないが `.gitignore` は区別するので、`Scratchpad/` のような綴りは通って追跡対象になる。docs で小文字を使うよう書いた
- 失ったもの: 配布先の CCNAVI.md が `{{scratch}}` を追跡される置き場の意味で使っていると、意味が変わる。`{{handoff}}` に直す必要がある
- 失ったもの: 過去の ADR の本文が、当時の名前と変わった
