# ADR-0190: 合流の衝突で先に合流した子を探す merge-blame をやめる

状態: 採用

## 状況

ADR-0137 は、finish の合流が衝突したとき、並行していた子とぶつかったなら先に合流した子の名前を出し、解くのは後から finish した子のワークツリーと名指しすると決めた。名前を探すために、実行ファイルに `write-and-push merge-blame` を持ち、sh が衝突のたびに呼んでいた。衝突したパスの一覧と解き方は、その前の文がすでに出している。名前は解き方を変えない補助の情報だった。

## 決定

`merge-blame` をやめる。衝突の文の末尾に「並行していた子とぶつかったときも、解くのは後から finish した側（この子）」の固定の 1 文を足す。

## 得たもの・失ったもの

- 実行ファイルの入口が 1 つ減り、衝突のたびのマージコミットの走査が無くなる
- どの子とぶつかったかは出力に出ない。知りたいときは `git log` で確かめる
- 配布済みの古い sh は新しい実行ファイルの `merge-blame` から空の答えを受け取る。古い sh は空の答えを無視して進むので、契約の版は上げない
