# ADR-0177: 「メインのチェックアウト」を「ユーザのチェックアウト」に改める

状態: 採用

## 状況

「メインのチェックアウト」は、git の用語 main working tree（`git worktree list` の先頭）の直訳だった。
ブランチ名の `main` と同じ連想を呼び、「main ブランチのチェックアウト」と読み違える人・エージェントが出た。
意味は、ユーザが開いているブランチのチェックアウトで、エージェントは直接書き換えず、
エージェントの作業場所（`.claude/worktrees/<名前>`）と対になる。

## 決定

呼び名を「ユーザのチェックアウト」に改める。挙動は変えない。文書・コメント・エージェントに見える文面・テストの語だけを替えた。

| 旧語 | 新語 |
|---|---|
| メインのチェックアウト | ユーザのチェックアウト |
| メインのツリー（チェックアウトを指すもの） | ユーザのチェックアウト |
| メインのワークツリー（チェックアウトを指すもの） | ユーザのチェックアウト |

定義は `.ccnavi/docs/terms.md` にある。`メインのエージェント`のように、チェックアウトを指さない `メインの…` は替えない。
旧語を受け付ける別名や、旧語の検出は足さない。

## 理由

持ち主が分かる語にすると、`main` ブランチと紛れない。「ユーザのチェックアウト」は改名の前は使われておらず、ほかの語と衝突しない。

## 過去の ADR の書き換え

ADR は決めた時点の記録で、通常は書き換えない。今回はユーザの了承を得て、用語の改名に限って本文の語を新語に替えた。
決定の中身（採った案・理由・番号）は変えていない。書き換えた ADR は 0129、0154、0164、0166 の 4 枚。

## 得たもの・失ったもの

得たもの: `main` ブランチと読み違えなくなる。
失ったもの: 過去の ADR や履歴を、旧語で検索しても当たらない。この ADR の旧語の対応表から辿る。

## 採らなかった案

| 案 | 採らなかった理由 |
|---|---|
| 元のチェックアウト | すでに別の意味で使っていて衝突する |
| 手元のチェックアウト | すでに別の意味で使っていて衝突する |
| 親のチェックアウト | 「親チケット」「親のワークツリー」と紛れる |
| 本体のチェックアウト | 「ccnavi 本体」と紛れる |
