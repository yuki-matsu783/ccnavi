# ADR-0173: xargs と find -exec の後ろが読むだけのコマンドなら読める形にする

状態: 採用

## 状況

`xargs` が先頭にあるコマンドと、`find` の `-exec` `-execdir` `-ok` `-okdir` は、文字列をコードとして
実行するものとして読めない形（`command-taken-as-code`）に縮退していた。縮退するとルールは生の文字列に当たり、
どれにもヒットしなければ確認（`PARSE_UNCERTAIN`）になる。非対話（`claude -p`）には確認に答える人がいないので、
`find … -print0 | xargs -0 wc -l` や `find … -exec wc -l {} +` のような読むだけの形まで実質的に拒否になった。
案内も英語で、どう書き直せば読めるかを言わなかった。

## 決定

- `xargs` はオプションと値を飛ばして最初に残った語が、`find -exec` 系は次の語（複数あればすべて）が、
  読むだけのコマンドの許可リスト（`grep` `egrep` `fgrep` `wc` `ls` `file` `stat` `sort` `uniq` `basename` `dirname` `echo`）に
  あるときだけ縮退させない。リストは定数 1 つにし、縮退を決める判定は 1 関数に収める
- 実行される語が決まらない形（語が無い、`{}` だけ）と、リストに無い形（`xargs rm`、`xargs sh script.sh`、`find -exec sh -c`）は従来どおり縮退する。
  `eval` `source` `.` の扱いは変えない
- 読めなかったときの案内を日本語にし、理由ごとに書き換え例を添える。非対話のセッションでは、確認に答えられないので書き直すことを 1 行足す
- 中で実行されるコマンドの層は変えない。リストにある語でも、拒否のルールは後ろのコマンドに適用される

## 理由

読むだけのコマンドを後ろに置く使い方は普通の作業で、毎回止めると非対話の作業が止まってしまう。
一方で `xargs` の後ろに何でも置けるようにすると迂回の入口になるので、リストを小さくして縮退する側を既定に残した。
`cat` `head` `tail` は中身をそのまま出すので入れない。

## 得たもの・失ったもの

- 得たもの: 読むだけの `find | xargs` と `find -exec` が非対話でも通る。案内が日本語になり、書き換えの次の一手が分かる
- 失ったもの: リストにあるコマンドの引数は標準入力から来る形を許す。`printf ~/.ssh/id_rsa | xargs grep -c x` のファイル名は
  ルールからは見えず、ファイル名を見るルールはこの形の引数には外れる。ユーザはこの緩みを了承している。
  `sort -o` のように書き込めるオプションを持つリスト内のコマンドは、そのオプションの扱いを拒否のルールに任せる

## 採らなかった案

- `xargs` を縮退の対象から外す。後ろのコマンドが何であっても読める形になり、`xargs sh -c` まで通る
- 案内だけを直す。読むだけの形が非対話で止まることは変わらない
- `cat` `head` `tail` も入れる。中身をそのまま出すので、ファイル名が見えないことの害が大きい

## 追記: `-` で始まる断片は書き込みの述語を含むときだけ止める

`find … -exec … \;` の後ろに続く述語（`-delete` など）を別のコマンドと読んで見逃さないために、`-` で始まる語が頭に来る
コマンドを一律で読めない形にした。これは回帰だった。シェルの読み取りは `\(` `\)` `\;` も引用された `'('` `';'` も
トークンの文字列が演算子と同じになり、区別できずにそこで切る。切れた後ろの `-name …` や `-n main.sh` までが止まり、
`find . \( -name x -o -name y \) -print` や `grep -e '(' -n main.sh` が #527 の前の確認（`UNDECLARED`）から読めない形（`PARSE_UNCERTAIN`）になった。

- 断片のどこかに書き込み・実行の述語（`-delete` `-exec` `-execdir` `-ok` `-okdir` `-fprint` `-fprint0` `-fprintf` `-fls`）があるときだけ、読めない形のまま残す。
  先頭の語だけを見ると `\; -name x -delete` の `-delete` を見逃すので、全語を見る。語は小文字のまま比べる（パスではなくオプションの語）
- `-print` `-name` `-o` `-not` `-n` などは標準出力に出すか絞り込むだけなので止めない
- 引用された演算子と本物の演算子の区別は直していない。別の issue で扱う
