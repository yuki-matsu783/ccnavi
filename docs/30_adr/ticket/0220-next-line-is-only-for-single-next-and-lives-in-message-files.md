# ADR-0220: 行頭の「次:」は次が 1 つに決まる行だけにし、文は文面ファイルに集める

状態: 採用

## 状況

連続する作業の指示は、前の作業が完了したときにその出力へ書く（思想のテーマ 5）。出力の行頭の語は `次:` `次は…` `次を実行する:` `流れ:` `あとは…` `案内:` と揺れていた。
成功したのに次を言わない操作（`ticket cancel`、`record-risk`、途中のフェーズの `confirm`、`approval-request --check`、`--fill-phases`、`learn --note`、親の `start`）があり、エージェントが手元の知識で手順を補っていた。
次の一手の文は、コードに直書きされたものが残り、同じ一手が場所ごとに別の文になりえた。

## 決定

| 決めたこと | なぜ | 採らなかった側 |
|---|---|---|
| 行頭の語を `次:` に寄せるのは、次が 1 つに決まる行だけ。選択肢の見出し `次の手:` と補足の `案内:` は残す | 読む側が `次:` の行を数えて、1 つに決まった次だけを拾える | すべての案内を `次:` にする |
| 1 回の出力の `次:` は 1 行、1 行に 1 手。後に続く手は `案内:` に置く | 1 行に複数の手を入れると、途中の手が読み飛ばされる | 複数の手を `次:` で並べる |
| 次の一手の文は文面ファイル（`next-cli.yml`）に置き、`NEXT_*`・`NOTE_*` の識別子で引く | 同じ一手が複数の場所で別の文にならない | コードに直書きする |
| 成功した操作は、言うべき次があれば `次:` を足す。状態から決まる次は実行ファイルが割り出し、sh は `status` を促す | 次を言わないと、エージェントが決まりを外れた道に進む | 次を `status` だけに任せる |
| ユーザがターミナルで打つ入口（`ccnavi-user-*.sh`）の出力は、事実の行に留める | エージェントへの通知は、拡張が渡す承認の文と `status` が受け持つ | 入口の出力にも `次:` を足す |
| `review_next` と `status` の「次の操作」は、識別子を持たないコード内の文のまま | 状態から文を組む関数で、文面ファイルの差し込みに収まらない | 文面ファイルへ移す |

## 得たもの・失ったもの

- 得たもの: 次が 1 つに決まる場面は `次:` の 1 行で言い、文面ファイルの 1 か所を直せば足りる
- 失ったもの: `次:` を 1 行に絞ったので、複数の手が続く場面（最後のフェーズのあとの finish と ready）は、後の手を `案内:` に回した
