# ADR-0189: 依頼のあとに HEAD が動いたときの説明を、断定しない固定の文にする

状態: 採用

## 状況

ADR-0156 は、依頼のあとに HEAD が動いて止めたとき、判定を変えずに理由を説明すると決めた。確かめられるときは見られていない変更と動いたコミット（最大 5 件）を並べ、確かめられないときは確認できないとだけ言う形だった。そのために、コミットを最大 100 件まで調べて置き場だけのコミットを除き、件名と作者を外から来た文字列として整え、祖先かどうかで文を分け、ミラー側の件数を数えていた。止める判定には効かず、説明のためだけの処理だった。

## 決定

判定（HEAD が動いた）は変えない。説明は「依頼時のコミットといまの HEAD が違う。何が変わったかユーザに確かめてもらい、依頼し直す」の固定の 1 文にする。動いたのがミラー側だけのときは、直し方が違うので、そのことを言う 1 文を足す。コミットの一覧、件数、祖先かどうかの出し分けはやめる。

## 得たもの・失ったもの

- 説明のための git の呼び出しと文の組み立てが無くなる。外から来た件名と作者を出さないので、整える処理も要らない
- エージェントはどのコミットが動いたかを出力から知れない。確かめるのはユーザに頼む

## 採らなかった案

- 固定の文に `git log 依頼時..いま` を添える。依頼時のコミットが祖先でないときは関係の無い履歴まで並ぶので、断定しない文にした
