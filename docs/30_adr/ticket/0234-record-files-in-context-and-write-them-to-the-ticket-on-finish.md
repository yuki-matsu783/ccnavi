# ADR-0234: セッションのコンテキストに乗ったファイルを記録し、finish でチケットの本文に書く

状態: 採用

## 状況

チケットを実行するのに、どのファイルがエージェントのコンテキストに乗ったかを、あとからチケットで確かめたい。
ツールの入力と結果は PostToolUse に届く。`finish` は閉じるチケットに欄を書き、そのまま親のブランチへ push する。
実行後チェックは、チケットの置き場の変更のうち「スクリプトだけが書く欄を除くと中身が同じ」ものだけを ccnavi 自身の書き込みとして外す。

## 決定

| 決めたこと | なぜ | 採らなかった側 |
|---|---|---|
| 記録はセッション単位にする。メインとサブエージェントは同じ記録に入り、同じセッションで扱ったほかのチケットのぶんも混ざる | 知りたいのは、そのチケットを進めたコンテキストに乗ったもの。混ざるのはコンテキストが実際に混ざったため | パスが子のワークツリーの下かで子を決める。親のツリーやワークスペースルートで読んだものが落ちる |
| `finish` は環境変数 `CLAUDE_CODE_SESSION_ID`（hook の `session_id` と同じ値）で、打ったセッションの記録を引く | `finish` はサブコマンドで、hook の入力を持たない | hook の PreToolUse で `finish` の打鍵を見て結び付ける。コマンドの字面の読み取りに頼る |
| 1 つのチケットを複数のセッションで進めた場合に備え、チケットのワークツリーの中のファイルを記録しているセッションも集め、セッションごとの小見出しで追記する（同じセッションは置き換える） | 前のセッションの記録が `finish` のセッションに無い | 打ったセッションのぶんだけを書く。前のセッションのぶんが落ちる |
| 本文の最後に、印と見出しの付いた「参照したファイル」の節として書く | frontmatter を膨らませない | frontmatter の欄にリストで書く |
| Bash は、引数と標準出力に出た語のうち、実在するファイルだけを拾う（best effort） | grep・find の結果もコンテキストに乗る | 引数だけを拾う。出力で読んだファイルが落ちる |
| 実行後チェックの照合は、コミット済みの版に節がまだ無いときだけ、節（印のあとが見出し 1 つとセッションの小見出しと空行と `- ` の行だけのもの）を除く | `finish` が足すたびに範囲外の変更として報告されないため。除く範囲を形で狭め、1 度書いた節の書き換えは報告する | 節をチケットと並べた別ファイルに書く。置き場のファイルが増え、照合の例外も別に要る |

## 得たもの・失ったもの

- 得たもの: 閉じたチケットに、作業中に参照したファイルの一覧が残る
- 失ったもの: 照合が 1 点緩む。エージェントが `finish` の前に、決まった形の節を本文の最後へ書き足しても検出されない。範囲・承認の判定には影響しない
- 失ったもの: Bash の推測は取りこぼしと取り違えがある。並行して書かれると 1 回ぶん落ちることがある
