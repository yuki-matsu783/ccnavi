# ADR-0185: ccnavi の命名に合うブランチ名は、番号の位置だけを issue の番号として読む

状態: 採用

## 状況

ADR-0182 は、名前に番号を含むブランチの判定を「前後が区切りか端」にした。位置は問わないので、
`feature-102-main-sh-の使い方の表示を-1-行足す-c3-検証用` の slug の `-1-` が `--issue 1` に一致し、
無関係な 4 件が候補になって `ccnavi-start.sh --issue 1` が終了コード 3 で止まった。

## 決定

| 決めたこと | なぜ |
|---|---|
| 名前が `<先頭の語>-<番号>-<slug>`（先頭の語は `CCNAVI_BRANCH_PREFIXES`）の形に合うなら、2 つ目の番号だけで比べる | ccnavi が切る名前では番号の位置が決まっていて、slug の数字は番号ではない |
| 形に合わない名前は ADR-0182 の規則のまま | `fix/152-y`・`issue-152`・`x-152` のような名前は番号の位置を決められない |
| 実行ファイルの `names_number` と `ccnavi-branches.sh` の jq を同じ規則にし、先頭の語は設定と環境変数から渡す | 判定が 2 か所にあり、片方だけ直すと逆戻りする |

## 得たもの・失ったもの

- 得たもの: slug の中の数字で無関係なブランチが候補になり、新規作業が止まらなくなる。
- 失ったもの: sh は環境変数 `CCNAVI_BRANCH_PREFIXES` だけを見る。設定ファイルだけに書いた先頭の語は、
  ターミナルから打った sh の jq には届かず既定のリストで読む。
- 形に合っても slug の字が許す範囲を超える名前（`feature-102-a/1`）は、形に合わない名前として読む。

## 採らなかった案

| 案 | 落とした理由 |
|---|---|
| 名前だけの候補を全て出さない | 形に合わない名前（`fix/152-y`）の候補を失う |
