# ADR-0203: テンプレートの配布は、配れないものを飛ばして知らせ、着手を止めない

状態: 採用

## 状況

完了した作業・レビュー計画のテンプレートは、共通レイヤーの `templates/` からプロジェクトのミラーへコピーされる。
コピーする前に、各テンプレートを共通として読めるか確かめる。配れないものがあるときの扱いを決める必要があった。

## 決定

| 決めたこと | なぜ | 採らなかった側 |
|---|---|---|
| error のあるテンプレートはコピーせずに飛ばし、着手は止めない。warn は止めない。型が定義に無いだけでは止めない | 定義が後から変わりうる | 型が定義に無いテンプレートも止める |
| 置き場そのものが読めない（リンク、途中がリンク）ときは、理由を返さずテンプレートを 1 本もコピーしない。ほかの設定のミラーと発言は止めない。置き場がリンクなのを知らせるのは `--lint` の側 | dotfiles 管理で `.ccnavi` や `config/common` の途中がリンクのとき、テンプレートの置き場があるだけで着手が止まる退行を避ける | 置き場が読めないときに着手を止める |
| ファイル名は `[A-Za-z0-9._-]` だけで英数字で始まるものに限る。空白や glob の文字を含む名前は配らず、「名前に使えない文字があるので配っていないテンプレート」として出力で言う | 単語分割で `cp` が失敗して、配布が半端に止まるのを避ける | 名前を問わずコピーする |

## 得たもの・失ったもの

- 得たもの: テンプレートに問題があっても、着手とほかの設定のミラーが止まらない
- 失ったもの: 配られなかったテンプレートは、出力や `--lint` を見ないと気づけない
