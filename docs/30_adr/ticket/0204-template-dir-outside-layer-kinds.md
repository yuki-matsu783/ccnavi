# ADR-0204: テンプレートの置き場は、ルール・フェーズ定義・配点の 3 本を回す LAYER_KINDS に入れない

状態: 採用

## 状況

共通レイヤーとプロジェクトのレイヤーは、ルール・フェーズ定義・配点の 3 本のファイルを、`settings.LAYER_KINDS` で回して処理する。
テンプレートの置き場（`.ccnavi/config/common/templates/` と `.ccnavi/config/project/templates/`）も同じレイヤーの下に置かれる。

## 決定

| 決めたこと | なぜ | 採らなかった側 |
|---|---|---|
| テンプレートの置き場は `settings.LAYER_KINDS` に入れない。共通と 1 つのレイヤー（自身のレイヤーか、プロジェクト）の和として、置き場を別に読む | ファイル 1 本ではなくディレクトリで、入れると 3 本の処理に影響する | `LAYER_KINDS` に入れる |

## 得たもの・失ったもの

- 得たもの: 3 本の設定の処理が変わらない
- 失ったもの: テンプレートの置き場の読み書きは、3 本とは別の経路で持つ
