# ccnavi の手引き

ccnavi を使う人向けの手引きの入口である。ccnavi が何をするツールかは[README](../../README.md)にある。
開発に参加する人は[開発の入口](../development.md)へ進む。

## 始めるとき

| 知りたいこと | 読むページ |
|---|---|
| dry-run で入れる、記録を読んで直す、enable に切り替える。実行ファイルとルールを配る | [導入と配布](install.md) |
| hook の登録、置き場、環境変数の値と既定 | [設定](settings.md) |
| 動かないとき、反映されないとき | [つまずきやすい点](troubleshooting.md) |

## 読む順の目安

1. [導入と配布](install.md)で dry-run から始める
2. 記録を読んで[ルールの書き方](rules.md)を直し、[設定の確かめ方](check.md)で確かめる
3. 記録が落ち着いたら enable に切り替える
4. チケットで作業を進めるなら[チケット](tickets.md)と[レビュー](review.md)へ

要求・設計・判断の理由は、開発者向けの文書にある。入口は[開発の入口](../development.md)の案内表。
