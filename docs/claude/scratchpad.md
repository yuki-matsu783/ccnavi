# 下書きと使い捨ての置き場

本番に入れないもの（設定のコピー、再現用のスクリプト、調べたときの出力、渡す前の下書き）は、
ワークツリーの中ならそのワークツリーの`scratchpad/`に置き、ワークツリーが無ければセッションのスクラッチパッドに置く。
渡すときは必ずパスを伝える。

- `scratchpad/`は`.gitignore`に入っているので追跡されず、`git status`にも出ない。`worktree remove`も止まらずに実行でき、
  ワークツリーを片付ければ一緒に消える
- チケットが結び付いたワークツリーでも、そのまま書ける。実行前の判定は、`scratchpad/`にチケットの範囲を適用しない。
  そのため、範囲に`scratchpad/*`を足す必要は無い
- 範囲の判定から外れるのは、ルート直下の`scratchpad/`だけ（大文字小文字も区別する）。`SCRATCHPAD/`・`scratchpadX/`・
  `docs/scratchpad/`と、`scratchpad`という名前のファイルは普通の作業対象で、範囲の外にあれば止まる
- `scratchpad/`が追跡されているリポジトリでは、実行後の監視とサブエージェント終了時の検査が、下書きを範囲外として
  報告する。そのときは下書きを消さず、そのリポジトリの`.gitignore`（または`.git/info/exclude`）に`/scratchpad/`
  があるかを確かめる。`ccnavi --lint`もこの状態を警告する
- ワークツリーがまだ無いとき（ワークスペースルートで設定の下書きを作るなど）は、セッションのスクラッチパッドを使う。
  ルート直下への書き込みは`main-tree`が止めるので、そこに`scratchpad/`を作っても書けない。セッションのスクラッチパッドの
  パスは、Environment欄に書いてある
