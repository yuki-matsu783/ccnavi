# 実行ファイルの境界

- ccnavi の実行ファイルはネットワークにつながない。実行ファイルが判断の材料にするのは、プロジェクトの
  ディレクトリの中で確かめられるもの（作業ツリー、git、承認済みチケット、マーカー、hook の payload）だけ
- ディレクトリの外にあるもの（マージリクエスト、レビューのスレッド、ホストの API、認証）は
  `.ccnavi/scripts/` の sh が取得して JSON ファイルに書き、そのパスを実行ファイルの `--result` に渡す。
  実行ファイルはその JSON を読んで、チケットを状態ごとの置き場へ移し、マーカーを置くだけ
- 操作を止めるか通すかは、hook と実行ファイルが判定する（P13）。sh が ccnavi の状態を読んで操作を止める処理は、
  hook と実行ファイルの判定に重ねた 2 段目の確認にあたる。sh に新しい判定を足したくなったら、先に hook の側に置けないかを検討する
- 実行ファイルには、ディレクトリの外へ情報を取りに行くコードを足さない。取りに行く処理は sh に任せ、
  実行ファイルには取ってきた結果の読み方だけを足す。sh と実行ファイルの間の契約は、この JSON の形で決まる（形は `ccnavi.md` の 9.10）
