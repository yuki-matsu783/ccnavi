# 実行ファイルの境界

- ccnavi の実行ファイルはネットワークに出ない。自分で見て判断するのは、プロジェクトの
  ディレクトリの中で把握できるもの（作業ツリー、git、承認済みチケット、マーカー、hook の payload）だけ
- その外にあるもの（マージリクエスト、レビューのスレッド、ホストの API、認証）は
  `.ccnavi/scripts/` の sh が取ってきて、`--result` に渡す。実行ファイルは写しを読んでチケットとマーカーを動かすだけ
- 止める・通すの判定は hook と実行ファイルが持つ（P13）。sh が ccnavi の状態を読んで止めるのは 2 重目の守り。
  sh に新しく判定を足したくなったら、hook の側に置けないかを先に考える
- 実行ファイルに「外を見に行く」コードを足さない。sh の仕事に分け、実行ファイルには「その結果をどう読むか」
  だけを足す。写しの形が sh と実行ファイルの契約。
