# 実行ファイルの境界

CLAUDE.md「実行ファイルの境界」の詳細。ccnavi の実行ファイル（`ccnavi/`）か `.ccnavi/scripts/` の sh を直すときに読む。

- ccnavi の実行ファイルはネットワークに出ない。自分で見て判断するのは、プロジェクトの
  ディレクトリの中で把握できるもの（作業ツリー、git、承認済みチケット、マーカー、hook の payload）だけ
- その外にあるもの（マージリクエスト、レビューのスレッド、ホストの API、認証）は
  `.ccnavi/scripts/` の sh が取ってきて、`--result` に渡す。実行ファイルが持つのは
  写しを読んでチケットとマーカーを動かすところだけ
- 止める・通すの判定は hook と実行ファイルが持つ（P13）。sh が ccnavi の状態を読んで止めるのは 2 重目の守りで、
  同じことを hook が先に止める。sh に新しく判定を足したくなったら、hook の側に置けないかを先に考える
- 実行ファイルに「外を見に行く」コードを足さない。足したくなったら sh の仕事に分け、
