# レビュー済み

入口: [ccnavi 承認ボードの要件](../requirements.md)

| ID | 区分 | 要件 |
|---|---|---|
| REQ-CHR-05 | 事象 | 承認者が依頼済み（`phases/<親>/<N>.requested`）でまだレビュー済みでないフェーズを「レビュー済みにする」で押したとき、Chrome 拡張は、親子のチケットと MR のスレッドとレビューを読み直して同梱の ccnavi の `confirm`（手元の `ccnavi review confirm` と同じコア）に判定し直させ、通るときだけ、レビュー待ちの子の `done/` への移動とマーカー（`actor` = PAT の持ち主、`via: chrome`）を 1 コミットで書くこと。依頼の後に先頭が動いていれば compare API の変更の一覧を渡し、打ち切られた（300 件）・依頼時の先頭が祖先でないときは「動いた」として渡して書かないこと（REQ-APV-18） |
| REQ-CHR-07 | 事象 | 承認者が、未解決の指摘が残る依頼済みのフェーズで指摘ごとの行き先（対応しない・このフェーズで直す・issue に回す）を選んで確定したとき、Chrome 拡張は、見せた指摘が変わっていないことを確かめ、書く前に PAT の権限を確かめ（足りなければ何も書かずに必要な権限名を出して止まり）、issue の作成、スレッドへの返信、スレッドの解決の順にホストへ書いてから、同梱の ccnavi の `decide` が答えた続きの子・マーカー・`done/` への移動を親のブランチへ 1 コミットで書くこと。「このフェーズで直す」の指摘には返信も解決もしないこと。何も選ばなければ全件「このフェーズで直す」とし、全件を一括で選び直せること。ホストへの書き込みが途中で止まったときは、コミットを積まないこと。コミットが済んだあとに、決めた内容のコメントを MR に投稿すること（投稿だけが失敗したときは、反映を戻さず、コメントだけ投稿できなかったと案内すること）。続きの子もマーカーも積むものが無いとき（直す指摘が無く、見せたあとに指摘が増えたとき）は、コミットを作らないこと。MR のコメントは作った・使った issue の URL の一覧を含め、指摘が 0 件の確定では投稿しないこと。ホストへ書き終えたあとにコミットが積めなかったときは、ホストの側は済んでいること・MR のコメントは未投稿であることを案内し、決める画面を閉じること。止まった後に決め直したときは、2 回目のコメントとマーカーの accepted は 2 回目の選択だけを表し、1 回目の決定はスレッドの返信に残ること |

- 「レビュー済みにする」は、依頼済みでまだレビュー済みでないフェーズに、MR のスレッドとレビューを読み、同梱の ccnavi の `confirm` が
  通すと答えたときだけ出す。通るかを決めるもの（依頼の記録・依頼の後にユーザが見るものが動いていないか・同じ MR か・変更要求・未解決のスレッド）は
  同梱の ccnavi が持つ
- スレッドの本文は承認の画面と同じ規則で描く（DOMPurify で消毒、隠れる書き方を通さない、HTML コメントは見える形で出す）
- 未解決の指摘が残るフェーズは、「レビュー済みにする」の代わりに、残った指摘の行き先を決める画面を開く。指摘ごとに 3 択（対応しない・このフェーズで直す・issue に回す）を同じ寸法のラジオで出し、何も選ばなければ全件「このフェーズで直す」。2 件以上なら全件を一括で選ぶ小さな行を出し、個別に選び直せる。場所・URL（http(s) のときだけリンク）・本文（1 行目と全文。承認の画面と同じ消毒）を並べる。見せ直して指摘が変わったら選び直し、確定中は全部押せない。Chrome で扱えない指摘は選択肢を出さず理由と「VS Code で」を出し、1 件でもあれば確定を出さない。0 件なら従来の「レビュー済みにする」。ホストへの書き込みが途中で止まったときは、済んだ issue・返信・解決と理由を出し、読み直して未解決の指摘だけ決め直すよう案内する
- 確定の結果は、レビュー済みにしたか・続きの子・作った issue（URL）・コミットを一言で出す。積むものが無かったときはその旨を、MR へのコメントだけが失敗したときは警告を、同じ欄に出す
- MR に Approve があれば書く前に外れうることを出す
- マーカーの `actor` は押したユーザではなく PAT の持ち主（手元の confirm はトークンの持ち主）。MR の作者本人でも通る（自己レビューは防がない）
- MR は親のブランチの開いた MR を引き、依頼の記録の番号と照合する。レビュー済みのフェーズには重ねて書かない
