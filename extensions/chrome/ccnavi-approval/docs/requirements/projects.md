# プロジェクトのリポジトリ

入口: [ccnavi 承認ボードの要件](../requirements.md)

- プロジェクトのリポジトリ: 設定画面でプロジェクト名（手元の `projects/<名前>` の名前）と、先に登録したワークスペースの
  リポジトリを選ぶ。置き場のパスは既定に固定（統合先の `.claude/settings.json` の `env` は読まない）。共通レイヤー・設定・互換のマーカーはワークスペースの統合先から、閉じたもの（`done/`）とプロジェクトのレイヤーはプロジェクトの統合先
  から読み、レイヤーはプロジェクトの統合先のレイヤーに共通レイヤーをコピーしたもので判定する（親のブランチの上のレイヤーは読まない）。Chrome の登録の名前は手元のディレクトリ名と揃える（ずれると、手元で取り込んだ後に
  判定し直したとき親子のチケットが止まる）
