# ccnavi と左パネル

ccnavi は、Claude Code の作業をルールとチケットで管理する仕組みです。

- ルールで、危険な操作を止めたり、確認を求めたりします。
- 作業をチケットにして、提案、承認、着手、レビューの順に進めます。
- 変更の大きさから、リスクの点数とレビューの要否を決めます。

左のアクティビティバーの ccnavi を押すと、画面の入口が並びます。使う順に、プロジェクト管理、チケット管理、ルール管理、リスク管理、フェーズ管理、テンプレート管理です。行にマウスを重ねると説明が出ます。

パネルのタイトルバーの ? でこの案内をもう一度開き、配色のアイコンで見た目を切り替えます。チケット制御（CCNAVI_TICKET_CONTROL）が disable のワークスペースでは、プロジェクト管理とルール管理だけが並びます。
