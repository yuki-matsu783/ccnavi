# 左パネル

アクティビティバーの ccnavi を押すと、画面の入口が並びます。

- プロジェクト管理: projects/ の一覧、clone・fetch・pull の実行
- ルール管理: ルールの編集と保存、判定を試す、hook の確認
- リスク管理 / フェーズ管理 / テンプレート管理: 設定の編集（チケット制御が有効なときだけ並びます）
- チケット管理: チケットのカンバン表示、承認とレビューの進行
- バグ報告: 不具合を再現する間の録画（ffmpeg があるとき）・スクリーンショット・ログを zip にまとめる

行にマウスを重ねると説明が出ます。パネルのタイトルバーの ? でこの案内をもう一度開き、配色のアイコンで見た目を切り替えます。
