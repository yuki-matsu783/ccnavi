# 左パネル

アクティビティバーの ccnavi を押すと、3 つの見出しが並びます。

- ユーザ待ち: あなたの操作を待っているもの。承認待ち・レビュー待ち・注意・取り込み待ち・フローの下書きを、種類ごとの件数と識別子で並べます。合計はアクティビティバーのアイコンのバッジに出ます。行を押すと、その画面と場所が開きます（承認待ちなら承認の画面、レビュー待ちならそのフェーズのレビュー完了）。「片付け」を押すと、マージした MR の状況を確かめます
- 進行中の親: 進めている親チケット。押すとチケット管理画面でそのカードが選ばれます
- 画面: 画面の入口（チケット管理・プロジェクト管理・ルール管理・リスク管理・フェーズ管理・テンプレート管理・取り込み待ち）

件数は、チケット管理画面を閉じていても、ファイルが変わるたびに読み直します。レビュー待ちと片付けは、押すまでリモートを見に行きません。チケット制御（CCNAVI_TICKET_CONTROL）が disable のワークスペースでは、チケットに関わる行は並びません。

行にマウスを重ねると説明が出ます。パネルのタイトルバーの ? でこの案内をもう一度開き、配色のアイコンで見た目を切り替え、虫のアイコンでバグ報告（不具合を再現する間の録画・スクリーンショット・ログを zip にまとめる）を始めます。
