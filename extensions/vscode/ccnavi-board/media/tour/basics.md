# プロジェクトを clone してチケットで進捗を管理する

1. プロジェクト管理で、projects/ の下に作業するリポジトリを clone します。fetch や pull もここから実行します。
2. チケット管理で、チケットをカンバンで見ます。列は作業の進み具合を表します。承認する内容はオーバーレイで確認してから承認します。

「ツアー実行」を押すと、プロジェクト管理の案内、チケット管理の案内の順に画面の吹き出しが進みます。途中でやめるとそこで終わります。画面の右上の ? で、いつでも見直せます。

チケット制御が disable のワークスペースでは、チケット管理は開けないので、プロジェクト管理だけを案内します。
