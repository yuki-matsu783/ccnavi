# テンプレート管理画面

同じ拡張に「テンプレート管理画面」がある。作業・レビュー計画のテンプレート（完了した親の計画と子のフローを 1 ファイルにまとめたもの）を読み、エージェントが書いた下書きを取り込む。
テンプレートの有効か・捨てた理由・取り込めるかを決めるのは実行ファイルで、拡張はその答えを並べるだけにする。拡張はテンプレートのファイルを直接書かない。書くのは取り込みのときの実行ファイルだけである。
チケット制御が `disable` のワークスペースでは開かない。

対象は 3 種。共通の設定（`.ccnavi/config/common/templates/`）、ワークスペースの設定（`.ccnavi/config/project/templates/`）、プロジェクト 1 つの設定（`projects/<名前>/.ccnavi/config/project/templates/`）。
画面上部の「設定」の欄で切り替える。欄は対象が 1 つでも出る。画面の中身は、対象の層（上の一覧）と、その対象に見える足し算の結果（下の読み取り専用の枠）で決まる。ルール管理・リスク管理と同じ並び（帯 → ツールバー → 錠 → 本体 → 足し算の枠）にする。

## 入口とタブ

| 項目 | 約束 |
|---|---|
| 入口 | サイドパネルの「テンプレート管理」と、コマンドパレットの「ccnavi ボード: テンプレート管理を開く」（`ccnaviBoard.openTemplates`）。どちらも開く先はワークスペースの設定 |
| タブの題 | 「ccnavi テンプレート管理: 共通の設定」「ccnavi テンプレート管理: ワークスペース」「ccnavi テンプレート管理: プロジェクト <名前>」 |
| 枚数 | タブは 1 枚。開いたまま押すと増やさず前面に出す |
| 対象の切り替え | 別の対象を選ぶと、そのタブの中身が入れ替わる。未保存の変更（開いているプレビュー・取り込みの途中）があれば「破棄して切り替えますか？」と聞き、やめれば前の対象と中身が残る |
| 裏に回したとき | 中身を保持する。裏で開いていた本文・取り込みの欄・下見は、表に戻したときもそのまま |
| 読み込み | 押したらまずタブを出し、「…を読み込み中…」を見せてから中身を入れる。読めなかったときもタブは閉じず、理由を中に出す |
| 制御が `disable` | 開かず、呼ばれても開かずに理由を知らせる。サイドパネルとコマンドパレットの入口も出ない |

## 一覧

一覧は、開いている対象の層のテンプレートだけを出す（共通の設定は共通の層、ワークスペースは self、プロジェクトはその層）。層の置き場のパスは、ツールバーの対象の欄の横に出す。

その下に、読み取り専用の枠「足し算」を出す（既定は閉じている）。足し算を選ぶ欄で、ワークスペースの足し算（共通の設定 + ワークスペースの設定）とプロジェクトごとの足し算（共通の設定 + そのプロジェクトの設定）を切り替える。表には、名前・由来の層・使われるか・捨てた理由を、実行ファイルが出した索引のまま出す。1 件の中身は、見たい層に対象を切り替えて上の一覧で開く。

各テンプレートには次を出す。

- 名前・層・説明・いつ使うか（`when`）
- 使える、使えない（使われない）、捨てた理由（足し算で捨てられたときの理由。足し算の枠の表にも出す。読めない・同じ中身の重なり・同名の衝突など、実行ファイルの答えのまま）、読み取り専用
- 検査の結果。error・warn・info を、色だけでなく文字のラベルでも出す

拡張はこれらを判定しない。同名の衝突でどちらが効くか、どこで捨てたかは、実行ファイルの答えを読むだけにする。

## 1 件を開く

テンプレートの見出しを押すと、次が見える。

- 計画の項の表（番号・種類・レビュー・待つ項）。全体計画（`plan`）とフィードバック計画（`feedback`）を分けて出す
- フローの要約（子ごとの名前・ノード数・つながり数・種類ごとの数）
- 本文。「本文を見る」で読む。制御文字と書式文字は、読める形の `\uXXXX` に置き換えて出す（実際のファイルの中身は変えない）
- 検査の指摘

この画面では本文もテンプレートも編集しない。

## 下書き

一覧の下に、エージェントが書いた下書き（ワークスペースのルートとツリーの `wip/proposals/templates/`）を出す。下書きには効力が無く、取り込むまでテンプレートとして使われない。
1 件ごとに次を出す。

- 名前と置かれたツリー（ワークスペースのルートは空）
- 取り込めるか（読めて error が無いか）。取り込めない下書きの「取り込む…」は押せない
- 同名のテンプレートが在るとき、その層の名前と「取り込むと置き換え」
- ほかのツリーに同じ中身の下書きが在るとき、そのツリーの名前
- 本文や説明に `TODO` が残っているときは、その印
- 検査に使ったフェーズ定義の層

開いた下書きには、計画（全体計画とフィードバック計画）・フロー・指摘を、テンプレートと同じ形で出す。下書きの本文は、取り込みの下見で差分か本文として見る。

## 取り込み

下書きの「取り込む…」を押すと、取り込みの欄が開く。

1. 取り込み先（共通の設定、または選んだ層）と置き換えを選ぶ。既定の取り込み先は、同名のテンプレートが在る層（無ければ共通の設定）。同名が在る層を選んだときは、置き換えを既定で選ぶ
2. 「下見」を押す。実行ファイルが、差分（同名がある）か、取り込む本文（新しく置く）と、指摘を返す。下見は何も書かない
3. 下見の内容を読んで、「この内容で取り込む」を押す

約束は次のとおり。

- 「この内容で取り込む」は、下見で見せた下書きのハッシュを実行ファイルに渡す。下見のあとに下書きが書き換わっていれば、何も書かず、「取り込めませんでした」と出す
- 画面からの取り込みは端末の確認を出さない。代わりに、見せた下書きとの一致（`--expect`）と、エージェントが Bash から打てない形であること（hook の止め）で守る
- 取り込みは作業中のチケットで止まる。共通の設定とワークスペースの設定は、どのツリーでも作業中のチケットが 1 つでもあれば止める。プロジェクトの設定は、そのプロジェクトの作業中のチケットだけで止める。止めているあいだは取り込みを押せず、理由を下見の欄に出す
- 取り込めたら、一覧と下書きを読み直し、書いたテンプレートと、取り込みで消した下書き（残したときはその場所）を出す

## 案内

ヘッダ右上の「?」から、基本の案内と使い方ごとの案内（足し算を読むとき・下書きを読むとき・下書きを取り込むとき）を選べる。ほかの設定の画面と同じく、案内の間は見本（`tours/templates.yml` の `sample:`）を描き、実際のテンプレートや取り込みの欄には触れず、拡張ホストへ操作を送らない。初回は拡張ホストが案内を頼み、閉じたら見たことを残す。

## 読み直しと監視

- テンプレートの置き場と、設定ファイル（`.claude/settings.json`・`.claude/settings.local.json`）を監視する
- 作業中のチケットが動いたときは、中身は読み直さず、取り込みを止めるかだけを取り直す
- 画面に未保存の変更が無いあいだは、置き場と設定ファイルが変わったら自動で読み直す
- 未保存の変更（開いているプレビュー・取り込みの途中）があるあいだは、中身を入れ替えず「ファイルの変更を検知しました」の帯（`#changed`）を出す。「更新」を押すと読み直し、開いているプレビューは破棄される
- 「更新」はいつでも押せる

## 実行ファイルが古いとき

`ccnavi --version --json` の `flags` に、テンプレート管理画面が使う引数（`--templates`・`--show`・`--import`・`--expect`・`--yes`・`--via`）が揃っていなければ、一覧を読まずに理由を画面の中に出す。
理由には、足りない引数の名前と、ワークスペースの ccnavi を更新すれば直ることを書く。

## 適用範囲外

- 本文の編集、テンプレートの改名、層の間の移動、テンプレートの削除、下書きの削除
- ボードのカードからテンプレート管理画面を開く入口。親のカードからその親の下書きを作る入口も無い（ボードの答えに、その親から下書きを作れるかを示す欄が無いため）
- 取り込み以外でのテンプレートファイルの書き込み
