# テンプレート管理画面

同じ拡張に「テンプレート管理画面」がある。作業・レビュー計画のテンプレート（完了した親の計画と子のフローを 1 ファイルにまとめたもの）と、エージェントが書いた下書きを読む。一覧・検索・表示だけの画面で、下書きの取り込みと編集は「取り込み待ち」の画面（[handoff.md](handoff.md)）で行う。
テンプレートの有効か・捨てた理由を決めるのは実行ファイルで、拡張はその答えを並べるだけにする。拡張はテンプレートのファイルを書かない。
チケット制御が `disable` のワークスペースでは開かない。

対象は 3 種。共通の設定（`.ccnavi/config/common/templates/`）、ワークスペースの設定（`.ccnavi/config/project/templates/`）、プロジェクト 1 つの設定（`projects/<名前>/.ccnavi/config/project/templates/`）。
画面上部の「設定」の欄で切り替える。欄は対象が 1 つでも出る。画面の中身は、対象の層（上の一覧）と、その対象に見える統合結果（下の読み取り専用の枠）で決まる。ルール管理・リスク管理と同じ並び（帯 → ツールバー → 本体 → 統合結果の枠）にする。

## 入口とタブ

| 項目 | 約束 |
|---|---|
| 入口 | サイドパネルの「テンプレート管理」と、コマンドパレットの「ccnavi ボード: テンプレート管理を開く」（`ccnaviBoard.openTemplates`）。どちらも開く先はワークスペースの設定 |
| タブの題 | 「ccnavi テンプレート管理: 共通の設定」「ccnavi テンプレート管理: ワークスペース」「ccnavi テンプレート管理: プロジェクト <名前>」 |
| 枚数 | タブは 1 枚。開いたまま押すと増やさず前面に出す |
| 対象の切り替え | 別の対象を選ぶと、そのタブの中身が入れ替わる |
| 非表示にしたとき | 中身を保持する。非表示の間に開いていた行と本文は、再表示したときもそのまま |
| 読み込み | 押したらまずタブを出し、「…を読み込み中…」を見せてから中身を入れる。読めなかったときもタブは閉じず、理由を中に出す |
| 制御が `disable` | 開かず、呼ばれても開かずに理由を知らせる。サイドパネルとコマンドパレットの入口も出ない |

## 一覧

一覧は、開いている対象の層のテンプレートだけを出す（共通の設定は共通の層、ワークスペースは self、プロジェクトはその層）。層の置き場のパスは、ツールバーの対象の欄の横に出す。

その下に、読み取り専用の枠「統合結果」を出す（既定は閉じている）。統合結果を選ぶ欄で、統合結果（共通 + ワークスペース）とプロジェクトごとの統合結果（共通の設定 + そのプロジェクトの設定）を切り替える。表には、名前・由来の層・使われるか・捨てた理由を、実行ファイルが出した索引のまま出す。1 件の中身は、見たい層に対象を切り替えて上の一覧で開く。

各テンプレートには次を出す。

- 名前・層・説明・いつ使うか（`when`）
- 使える、使えない（使われない）、捨てた理由（統合結果で捨てられたときの理由。統合結果の枠の表にも出す。読めない・同じ中身の重なり・同名の衝突など、実行ファイルの答えのまま）、読み取り専用
- 検査の結果。error・warn・info を、色だけでなく文字のラベルでも出す

拡張はこれらを判定しない。同名の衝突でどちらが効くか、どこで捨てたかは、実行ファイルの答えを読むだけにする。

## 1 件を開く

テンプレートの見出しを押すと、次が見える。

- 計画の項の表（番号・種類・レビュー・待つ項）。全体計画（`plan`）とフィードバック計画（`feedback`）を分けて出す
- フローの要約（子ごとの名前・ノード数・つながり数・種類ごとの数）
- 本文。「本文を見る」で読む。制御文字と書式文字は、読める形の `\uXXXX` に置き換えて出す（実際のファイルの中身は変えない）
- 検査の指摘

この画面で本文は読むだけ。

## 下書き

一覧の下に、エージェントが書いた下書き（`wip/handoff/` に置かれた、種類が `template` のもの。実行ファイルの `--templates --json` の `drafts[]`）を出す。下書きには効力が無く、取り込むまでテンプレートとして使われない。
この画面で下書きは読むだけにする。取り込み・保存・改名・移動・削除の操作は持たない。取り込みは「取り込み待ち」の画面（[handoff.md](handoff.md)）で行う。
下書きの節に「取り込み待ちを開く」を置く。押すと取り込み待ち画面が開く（プロジェクトの設定を見ているときはそのプロジェクトのツリー、それ以外はワークスペースのツリー）。
1 件ごとに次を出す。

- 名前と置かれたツリー（ワークスペースのルートは空）
- 検査の指摘に error があるとき、その印。読み込めない下書きの印
- 本文や説明に `TODO` が残っているときは、その印

開いた下書きには、パス・説明・使う場面・指摘・計画（全体計画とフィードバック計画）・フローを、テンプレートと同じ形で出す。下書きの本文と取り込み先との差分は、取り込み待ち画面で見る。

## 改名・移動・削除

テンプレートの改名・移動・削除は、この画面にも実行ファイルにも無い。ファイルを直接操作する（その間は衝突の検査と作業中の錠を通らない）。

## 案内

ヘッダ右上の「?」から、基本の案内と使い方ごとの案内（統合結果を読むとき・下書きを読むとき）を選べる。ほかの設定の画面と同じく、案内の間は見本（`tours/templates.yml` の `sample:`）を描き、実際のテンプレートには触れず、拡張ホストへ操作を送らない。初回は拡張ホストが案内を頼み、閉じたら見たことを残す。

## 読み直しと監視

- テンプレートの置き場、下書きの置き場（`wip/handoff/`。ワークスペースのルート・プロジェクト・ワークツリー）、設定ファイル（`.claude/settings.json`・`.claude/settings.local.json`）を監視する
- この画面は何も書かないので、これらが変わったら自動で読み直す（開いた行と本文は、読み直しで閉じる）
- 「更新」はいつでも押せる

## 実行ファイルが古いとき

`ccnavi --version --json` の `flags` に、テンプレート管理画面が使う引数（`--templates`・`--show`）が揃っていなければ、一覧を読まずに理由を画面の中に出す。
理由には、足りない引数の名前と、ワークスペースの ccnavi を更新すれば直ることを書く。
`features` に `handoff` が無い実行ファイル（取り込み待ち画面を使えない古い版）では、一覧は読めるが、「取り込み待ちを開く」を無効にして「実行ファイルが古い版です。組み立て直してください」の理由を出す。

## 適用範囲外

- ボードのカードから**テンプレート管理画面を開く**入口は無い。カードの「テンプレートの下書きを作る」で下書きを作ったあとに開くのは、取り込み待ち画面である
- テンプレートのファイルの書き込み（取り込み・保存・改名・移動・削除）。取り込みは取り込み待ち画面、改名・移動・削除はユーザがファイルを直接操作する
